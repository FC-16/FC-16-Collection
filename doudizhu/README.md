# 斗地主 ・ FC-16

经典三人纸牌斗地主。你执南家（屏幕下方），对阵东家（右上）、西家（左上）
两台确定性 AI；随机首叫、依次叫分（1/2/3 分或不叫），叫 3 分立即成为地主，
全桌不叫则重新发牌。地主收取 3 张明示底牌（顶栏中央常驻展示），先出完牌的一家
获胜。无任何二进制资产：牌面（3×5 点数 + 5×5 花色迷你字形）、牌背、界面全部
程序化绘制，SFX 与背景音乐由 `_init` 按 SPEC §5.2 布局 poke 写入。

## 规则

- 54 张牌，大小序 3<4<…<K<A<2<小王<大王；发 17×3，留 3 张底牌。
- 牌型：单张、对子、三张、三带一、三带对、顺子（≥5 连单，2 与王不入顺）、
  连对（≥3 连对）、飞机（≥2 组连续三张，可带同数量单张或对子翅膀）、
  四带二（两单或两对）、炸弹（压一切非炸）、王炸（最大）。
  同型比较主牌张数与最大牌值；跟牌必须同型更大或炸弹/王炸；不要则过；
  连续两家过即新一轮，由最后出牌者任意出合法牌型。
- 计分：得分 = 底分（叫分）× 倍数；炸弹与王炸每打出一个倍数 ×2；
  春天（地主胜且两农民一张未出）与反春（农民胜且地主只出过首手）再 ×2。
  地主赢则 +2×得分、两农民各 -1×得分，输则反向；本卡带只累计你的净积分。
- 存档：`dset` 槽 0 = 累计积分，槽 1 = 局数（`fflush` 落盘）。

### 简化项

- 飞机翅膀不与三张主牌同点数（点数恰为 3 的连续段整体作机身，其余全部作翅膀），
  四带二的翅膀可为一张对子拆作两单。
- AI 从不主动出四带二（识别与被压判定完整支持），残局倾向直接贪心出完。
- 无加倍/抢地主/明牌等变体。

## AI 策略（两台共用，确定性）

- 叫分：手牌强度估值（2×2、王 +3/+4、A +1、炸弹 +3、王炸再 +3），≥13 叫 3 分、
  ≥8 叫 2 分、≥5 叫 1 分，只能叫比当前更高的分。
- 拆牌：王炸/炸弹预留 → 从小端贪心抽最长顺子 → 连对 → 连续三张合并为飞机 →
  三张 → 对 → 单。
- 主动出牌：整手能一手出完直接出完；否则按「顺子 > 连对 > 飞机 > 三张（带小单翅）
  > 对 > 单」优先出最长最小的小牌型；对手报单（≤2 张）时少送小单/小对，
  农民队友报单时优先送最小单张。
- 跟牌：能整手压过直接赢；队友（农民之间）领先一律让牌；否则生成同型最小压牌
  （优先不拆结构：先用散单，再拆对/三）；对手逼急（剩余 ≤5 张 / 自己 ≤7 张 /
  压 2 与王 / 压炸弹）才动用炸弹，王炸门槛更高（对手 ≤3 张或自己 ≤6 张）。
- 所有 AI 出牌在提交前再过一遍 `analyze` + `beats` 校验，任何生成异常都会转为
  「不要」，保证 AI 永不非法出牌。Ⓡ 提示对玩家手牌复用同一套逻辑。

## 操作

| 键 | 功能 |
|---|---|
| ⬅ ➡ | 移动手牌光标（按住自动重复） |
| ⬆ / Ⓐ | 抬起或放回当前牌 |
| ⬇ | 放回当前牌 |
| Ⓑ | 清空选择 |
| Ⓧ | 出牌（所选须构成合法牌型且压得过上家） |
| Ⓨ | 不要/过（先出时不可过） |
| Ⓡ | 提示：给出并选上一手建议 |
| Ⓐ / Start | 标题开始游戏；结算后再来一局 |

叫分阶段：⬅➡ 在「不叫 / 1分 / 2分 / 3分」间选择（低于当前最高分的选项变灰），
Ⓐ 确认。要不起时画面会提示「要不起，Ⓨ不要」。

## 构建与运行

```bash
cargo run -p fc16-tools --bin fc16mk -- --name "斗地主" --author "FrostMiKu" \
  --version 1 --save-id doudizhu --code demo/doudizhu/doudizhu.lua --cover 80 \
  --out demo/doudizhu/doudizhu.fc16 --png demo/doudizhu/doudizhu.fc16.png
cargo run -p fc16-host -- demo/doudizhu/doudizhu.fc16
```

开发期验证参考：`--frames 400 --screenshot` 走查标题/牌桌；用 `--script` 注入
「B 清选 → A 抬牌 → X 出牌 → Y 过」的周期输入即可让三家 AI 长跑完整对局并结算。
