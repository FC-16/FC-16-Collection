# 打砖块 ・ FC-16

Breakout / Arkanoid 风格的街机打砖块。挡板带惯性微加速，反弹角由击点
位置决定（越靠边缘越尖角），球恒速推进并随关卡小幅提速；打碎全部可破坏
砖即可过关。美术（逐像素烘焙精灵）与音乐（A 小调四声部芯片 BGM）均为
本卡带原创，全部由 `_init` 程序化生成，卡带不携带二进制资产。

## 规则

- 3 条命，掉球扣命；球粘在挡板上，Ⓐ 发射。
- 砖块有 1-3 击多耐久（外观随破损渐变、音高随剩余耐久变化）；
  `#` 为不可毁钢砖；金砖内含道具胶囊。
- 清光全部可破坏砖过关，共 8 关；最高分与最远关卡自动存档
  （`dset` + `fflush`，save-id `breakout`）。

## 道具（接住胶囊生效）

| 胶囊 | 效果 |
|---|---|
| E 加宽 | 挡板加宽 10 秒 |
| L 激光 | 挡板变身双炮 10 秒，Ⓐ 发射双束激光 |
| M 多球 | 球数 ×3（同屏上限 6） |
| N 减速 | 球速 ×0.68 持续 8 秒 |
| + 加命 | 命数 +1（上限 6） |

同屏最多 3 枚胶囊掉落；掉球后全部时效效果清零。

## 关卡（字符画编码，每行 15 格）

| 关 | 名称 | 图样 |
|---|---|---|
| 1 | 开幕 | 橙绿满排 + 道具砖 |
| 2 | 棋盘 | 交错砖阵 |
| 3 | 金字塔 | 逐层加宽的 3/2/1 击塔 |
| 4 | 堡垒 | 钢砖外墙 + 内部道具库 |
| 5 | 双子 | 双柱塔楼与中央通道 |
| 6 | 彩虹 | 蓝橙绿拱形层 |
| 7 | 蜂巢 | 2/3 击交错 + 钢钉点缀 |
| 8 | 决战 | 钢栅栏纵列 + 密集混编阵 |

## 操作

| 键 | 功能 |
|---|---|
| ⬅ ➡ | 移动挡板（带惯性微加速，挡板速度还会给球加英式旋转） |
| Ⓐ | 发射小球 / 激光形态下发射双束激光 |
| Start | 暂停 / 继续 |
| Select | 音乐开关（任意时刻） |

键盘默认映射：W/A/S/D 方向、J/K/U/I 面键、Q/L 扳机、Tab / Enter。

## 演出

砖碎四溅粒子、球拖尾、挡板受击闪光、胶囊飘落起伏旋转、过关清屏光波
扫场、掉球时挡板爆碎 + 全屏显示期调光（`pal` p=1）压暗的失败结算。

## 构建与运行

```bash
cargo run -p fc16-tools --bin fc16mk -- --name "打砖块" --author "FrostMiKu" \
  --version 1 --save-id breakout --code breakout/breakout.lua --cover 30 \
  --out breakout/breakout.fc16 --png carts/breakout.fc16.png
cargo run -p fc16-host -- breakout/breakout.fc16
```

headless 验证（`--script` 可按帧注入按键脚本，覆盖开始、发射、左右移动、
掉球与重生路径）：

```bash
cargo run -p fc16-host -- breakout/breakout.fc16 --frames 400 --screenshot out.png
```
