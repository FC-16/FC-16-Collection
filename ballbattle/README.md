# 球球大作战 · FC-16

FC-16 幻想主机上的完整 Agar.io 类演示卡带：1024×1024 竞技场里从一粒小球成长为
巨无霸，吞噬 AI 球与食物豆，总质量 600 即告胜利；支持分身、吐球与同体聚心合体
的多球操作。物理、AI、镜头、美术与音乐全部程序化生成（SFX/BGM 由 `_init`
逐字节写入，卡带不携带二进制资产；颜色全部直取 SPEC §2.2 固定色表）。

## 规则

- 竞技场 1024×1024，四边亮墙围界；初始 12 个 AI 家族（质量 60~300，玩家开局
  144 居中游）+ 160 颗食物豆。球数上限按队分账：AI 全体 ≤ 24、玩家 ≤ 4，互不挤占。
- **吞噬判定**：半径大 ≥15% 且中心距 < 大半径 − 小半径×0.4 时，大球吞掉小球，
  获得对方 **80% 质量**（r = √质量，半径平滑增长）；同族互不吞噬；玩家分身被
  吃光才算失败，AI 之间同样互相吞食；食物豆被吃后延时在别处重生保持总量。
- **速度曲线**：`v_max = 120 / √r` px/s——大球明显慢、小球明显快（r=12 约
  34.6 px/s，r=45 约 17.9 px/s，相差近一倍），分身前冲也按各自球半径套用同一曲线。
- **总质量 600 即胜利**；被吃光所有分身则进入死亡结算。Ⓐ 再来一局，Start 回标题。
- **开局保护**：前 3 秒玩家不可被吞（青色脉动环提示），避免出生即遭秒吞。
- 最高纪录（峰值质量 / 最长生存 / 最高吞噬）`dset(0..2)` + `fflush` 持久化，
  音乐开关存槽位 3。

## 多球机制（Ⓐ 分身 / Ⓧ 吐球 / 聚心合体）

- **Ⓐ 分身**：对局中按 Ⓐ，所有"可分身"的球（单球质量 ≥ 40，两半各 ≥ 20；玩家
  总球数 ≤ 4）沿当前移动方向一分为二（各半质量）；新球获得沿方向的前冲初速
  （9 px/帧，摩擦衰减），前冲期（30 帧）内跳过同体排斥。**分身不受冷却限制，
  可以连按**：144 → 72×2 → 36×4 一气呵成（1 变 2、2 变 4），边界只由单球质量
  ≥ 40 与家族 ≤ 4 决定。**不可分身时绝不静默失败**：拒绝音 + 飘字说明原因
  （质量不足 / 球数已满），左上面板常驻 Ⓐ 分身就绪状态与合体倒计时。
- **同体聚心与合体**：同一玩家的多个球持续受朝"全体分身质量加权质心"的缓慢吸引
  （前冲期除外）——不推方向键也会慢慢聚拢；**合体冷却 6 秒**（每球独立，分身时
  起算、再分身时重置）未到时吸引力用弱档（分身仍可拉开距离），冷却结束后靠近重叠
  即自动合体：质量相加、位置取大球、速度按质量加权。
  手感：分身出去 → 慢慢飘回质心 → 合为一体。
- **Ⓧ 吐球**：按 Ⓧ，**所有达标的分身各沿行进方向吐出一颗球**——本球 −16 质量，
  吐出质量 12 的小球（半径 ≈3.5，初速 7 px/帧衰减）。吐出的球**不受玩家控制**，
  任何球都可以吃：自己可以吃（用来喂小分身），其他玩家/AI 也可以吃。
  吐球门槛按单球计（质量 ≥ 36）：同一玩家里质量太小的球吐不了，大球照常能吐；
  场上吐球上限 64，超限删最旧；若按 Ⓧ 时所有分身都不达标，拒绝音 + 飘字提示。
- AI 同样会分身（每族至多 2 球，AI 全体受 24 球预算约束、与玩家的 4 球互不挤占）
  并遵守同一套聚心/合体规则。

## 操作

| 键 | 功能 |
|---|---|
| ⬅⬆⬇➡ | 向该方向加速（斜向归一；松开缓慢滑行并聚向质心） |
| Ⓐ | 对局中分身 / 标题开始 / 结算后再来一局 |
| Ⓧ | 对局中吐球（全部分身各吐一颗） |
| Start | 结算画面回标题 |
| Select | 音乐开关（标题 / 对局 / 胜利庆祝中均可） |

## AI 三层状态机

每 AI 出生时用 `rnd` 生成个性参数（侵略性 / 谨慎度 / 转向迟钝），行为差异化；
全部决策走本局确定性随机流，`--seed` 固定即可逐帧复现。

- **L1 战略层（每 ~30 帧 + 迟滞/最短驻留 45 帧，防抖动）**：
  全局模式 = 逃跑 > 狩猎 > 发育 > 游走。逃跑：存在 r ≥ 我×1.15 且在感知半径内
  并逼近（按 30 帧预测）的威胁，脱离后还有一段迟滞；狩猎：视野内可吃目标，近而
  优、玩家小分身高价值加权；发育：周边有食物密度；游走：随机航点兜底。
- **L2 战术层（每 ~10 帧）**：发育 = 8×8 密度格打分（数量/距离，吐出的球按 3 倍计）
  选最优簇；狩猎 = 拦截预判（目标点 = 猎物位置 + 猎物速度 × 我的到达时间）并校验
  "我的到达时间 < 猎物逃逸时间"（比速优势或已贴身），猎物近墙时拦截点钳在墙内
  形成切线封堵；**分身突袭**子状态：分身就绪、预测分身后仍吞得下、距离 60~210 时
  朝预判点分身追击（AI 每族球数上限 2）；逃跑 = 威胁反向 + 切向抖动合成逃逸向量，
  被贴身且分身就绪时向逃逸方向分身（小球更快）换取爆发。
- **L3 反应层（每帧）**：转向力合成——大球贴身排斥（应急回避）、墙体回避、
  同体合体吸引、所在密度格食物吸引。

## 特性

- 球体绘制：主色圆 + 高光斑 + 同色系深色描边（直接查 §2.2 色表选色，不做色号
  算术），呼吸微颤；球心显示质量数字（r ≥ 18）；玩家分身有朝向小眼睛与保护环，
  
- **绘制层级**：食物豆 → 吐出的球 → 光环 → 全部球按质量升序绘制（**大球压在
  小球上层**，玩家的与 AI 的混排）→ 粒子 → 飘字。
- HUD：左上总质量 / 家族名次 / Ⓐ 分身就绪状态 / 合体倒计时（按实体总质量计），
  右上前四名排行榜（按家族总质量聚合，玩家行青色高亮），右下 56px 小地图（球按
  相对半径画点，每个玩家分身带白框 + 当前视野框），左下轮播提示。
- 死亡演出：镜头震动 + 显示期调色红闪 + 粒子爆裂 + 扩散环；胜利有烟花庆祝演出。
- 结算面板：生存时间 / 峰值质量 / 吞噬数 / 家族名次，破纪录行带 ★ 闪烁。
- 音频：吃豆音高随体型下降（8 档）/ 吞球下咽 / 分身弹开 / 吐球 / 拒绝提示 /
  死亡坠落 / 胜利号角 / 新纪录旋律；原创 C 大调五声 8 小节循环 BGM（ROUND 旋律 +
  TRIANGLE 琶音 + BASS 贝斯 + 鼓组，PATTERN BEGIN/END 回环，占 ch4-7，
  游戏音效走 ch0-2）。

## 构建与运行

```bash
cargo run -p fc16-tools --bin fc16mk -- --name "球球大作战" --author "FrostMiKu" \
  --version 1 --code demo/ballbattle/ballbattle.lua --cover 120 \
  --out demo/ballbattle/ballbattle.fc16 --png demo/ballbattle/ballbattle.fc16.png
cargo run -p fc16-host -- demo/ballbattle/ballbattle.fc16
```

headless 验证（零输入不会开局；用 `--script` 注入 Ⓐ 开始，注意 seed 0 会被宿主
映射为随机种子，固定请用 `--seed 1`）：

```bash
cargo run -p fc16-host -- demo/ballbattle/ballbattle.fc16 --frames 300 \
  --screenshot out.png
printf '60 key 4\n62 key -\n100 key 4\n102 key -\n280 key 6\n282 key -\n' > script.txt
cargo run -p fc16-host -- demo/ballbattle/ballbattle.fc16 --frames 900 \
  --seed 1 --script script.txt --screenshot out.png
```
