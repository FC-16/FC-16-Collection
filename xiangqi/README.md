# 中国象棋 · FC-16

FC-16 幻想主机上的完整规则中国象棋。9×10 棋盘、红黑各 16 子，
双人热座与人机对弈两种模式，程序化烘焙的拟物棋盘与棋子、芯片音效与
五声音阶循环 BGM，战绩持久化存档。

## 规则实现

全部走法规则完整实现，走子前先做伪合法生成、再模拟走子过滤送将：

| 棋子 | 规则 |
|---|---|
| 车 | 直线滑行，遇第一个子为止（敌可吃、己阻挡） |
| 马 | 日字跳，蹩马腿（沿主轴相邻格有子则禁走） |
| 炮 | 空线直行；吃子须隔恰好一个子（翻山） |
| 相/象 | 田字走，塞象眼（对角中点有子禁走），不得过河 |
| 仕/士 | 九宫内斜行一格 |
| 帅/将 | 九宫内直行一格；**将帅照面禁手**（同列无隔子时不得形成直接对面，双向生效） |
| 兵/卒 | 过河前只能直进，过河后可横移一步，无升变 |

- 走子后若己方将/帅被攻击（含照面）则该走法非法（送将禁着）；
- 每步走完立即检测对方：被将军时显示"将军！"横幅与将位红圈闪示；
- 对方无任何合法走法时终局：被将军为**将死**，未被将军为**困毙**，走子方胜。

**简化项**：不实现长将 / 长捉禁着、重复局面判和与自然限着（预发布
演示卡带从简；对局可随时悔棋或 Start 回标题重开）。

## AI 策略

- 极小极大 + α-β 剪枝（fail-soft），深度 2：黑方每一手（根）穷举，
  对每个候选模拟红方**最佳回应**（同层完整过滤送将，绝不假设对手失误）；
- 评估函数 = 子力价值（车 9、炮 4.5、马 4、相/仕 2、兵 1、过河兵 2，
  帅以将死分兜底）+ 位置微调（兵推进奖励与底线老兵减值、马靠中、
  车炮中列加分、车炮四方向首格机动性计数）；
- 根走法级**分帧搜索**（每帧限量处理 2 个根走法），思考期间顶栏显示
  "思考中"；
- 同分取首个最佳，不使用随机数——同一局面永远走出同一手（确定性）；
- 人机模式玩家执红先行，悔棋一次退回到玩家上一手前（AI 思考中按
  Ⓧ/Ⓨ 亦可取消思考并悔棋）。

## 操作

| 键 | 功能 |
|---|---|
| ⬅ ➡ ⬆ ⬇ | 移动光标（按住约 1/4 秒后自动重复） |
| Ⓐ | 选子（显示全部合法落点：空位金点、可吃橙框）/ 再按走子 / 按于己方另一子换选 |
| Ⓑ | 取消选择 |
| Ⓧ / Ⓨ | 悔棋（人机模式退回到玩家上一手前） |
| Select | BGM 开关（状态存档） |
| Start | 回标题；终局画面 Ⓐ 再来一局 |

标题画面 ⬆⬇ 选择模式，Ⓐ/Start 开始；战绩（红/黑胜场与总局数）
持久化于存档槽 0-2。

## 视觉与音频

- 棋盘木色底 + 竖纹抖动、深棕网格、河界"楚 河 / 汉 界"、九宫斜线、
  炮兵位四角十字标记；上一步走子痕迹（起点方点 + 终点角框）；
- 棋子为 `_init` 时 poke 烘焙的 16×16 圆片精灵（象牙底、环色双环、
  左上高光、下缘阴影、刻字阴影），红方红环红字 / 黑方深环深字；
- 走子滑行动画、被吃子闪白与碎片粒子、将军横幅、终局压暗演出；
- SFX（选子 / 走子 / 吃子 / 无效 / 将军 / 胜负 / 悔棋）与 C 宫五声
  四小节循环 BGM（ORGAN 旋律 + TRIANGLE 和声 + BASS 低音，ch5-7）
  全部由 `_init` 按 SPEC §5.2 布局位写入，卡带不携带二进制音频资产。

## 构建与运行

```bash
cargo run -p fc16-tools --bin fc16mk -- --name "中国象棋" --author "FrostMiKu" \
  --version 1 --save-id xiangqi --code xiangqi/xiangqi.lua --cover 30 \
  --out xiangqi/xiangqi.fc16 --png carts/xiangqi.fc16.png
cargo run -p fc16-host -- xiangqi/xiangqi.fc16
```

封面取 headless 第 48 帧标题画面（棋盘全貌 + 匾额 + 模式选项）。
