# 华容道 · FC-16

FC-16 幻想主机上的三国华容道（Klotski）滑块谜题。4×5 木盘十枚棋子
（曹操 2×2、关羽 2×1 横、张飞/赵云/马超/黄忠 1×2 竖、四卒 1×1，
恰占 18 格留 2 空位），把曹操滑到下方中央出口即胜。

全部资产程序化：木纹滑块精灵 `_init` 逐像素 poke 烘焙（16×16 瓦片
sspr 3× 绘制）、SFX 与五声 BGM 按 SPEC §5.2 位写入，卡带不携带二进制资产。

## 规则与计步

- 滑块只可滑入**相邻空位**，一次一格；不可斜移、跳跃或穿过其他块；
- **每滑动一格计一步**（本卡带计步口径，即"单位步"）；
- 曹操左上格到达 (1,3)（与底边中央出口对齐）后自动走出棋盘，进入结算。

> 公开资料中的"横刀立马最少 81 步"是**指移步**口径（一次抓起一块连滑、
> 允许拐弯算一步，Martin Gardner 1964 年给出）；按逐格计的**单位步**
> 口径其最少步为 116（与 tmuetze.de 的公开分析一致）。本卡带以单位步
> 计步，选关界面"少"列即该口径的最少步，达成时触发"最少步达成"特别演出。

## 操作

| 键 | 功能 |
|---|---|
| ⬅ ➡ ⬆ ⬇ | 直接推动当前高亮块（推不动则改选该向最近的块；按住方向自动连续推动） |
| Ⓐ / Ⓑ | 悔棋（无限栈，步数回退；结算画面 Ⓑ 重来本关） |
| Ⓧ | 重开本关 |
| Ⓨ | 可动块高亮提示开关（块右上角小金点） |
| Ⓛ / Ⓡ | 上一关 / 下一关 |
| Select | BGM 开关（存档记忆） |
| Start | 选关；结算画面 Ⓐ 下一关、Start 选关 |

选关界面"佳"列为该关最佳步数（dset 存档），达成 ≤ 最少步时金色高亮。

## 视觉与音频

- 木托棋盘（底边中央 2 格开口即出口，口内金色下行箭头）、格线盘底；
- 滑块为烘焙木纹块 + 色系描框 + 角部钉饰：曹操黑漆描金、关羽绿袍、
  张飞玄铁、赵云银蓝、马超锦紫、黄忠琥珀、小卒原木，刻字带描边印章；
- 滑块滑动缓动（ease-out）、推动受阻抖动、可动块提示点、光标四角括号；
- 曹操出关加速滑出棋盘（棋盘裁剪）＋胜利横幅＋彩带；达成最少步时
  金框闪烁、加长号角与"最少步达成！"特别演出；
- 顶栏：关卡名 / 步数 / 最佳；侧栏：竖排"华容道"、关卡号与出口标记；
- SFX（推动木响、无效闷响、悔棋、菜单、出关、过关旋律、破纪录号角）
  与 C 宫五声四小节循环 BGM（ORGAN/TRIANGLE/BASS，ch5-7）。

## 构建与运行

```bash
cargo run -p fc16-tools --bin fc16mk -- --name "华容道" --author "FrostMiKu" \
  --version 1 --save-id klotski --code demo/klotski/klotski.lua --cover 90 \
  --out demo/klotski/klotski.fc16 --png demo/klotski/klotski.fc16.png
cargo run -p fc16-host -- demo/klotski/klotski.fc16
```

封面取 headless 第 90 帧标题画面。存档槽：0-9 各关最佳步数、
10 音乐开关、11 提示开关、12 上次关卡（save_id `klotski`）。

## 验证记录

- **可解性与最少步**：BFS（单位步，状态按同类互换规范化）复算上表；
  "公开"列与 EOP 公开步数表逐关一致，横刀立马单位步 116 亦与
  tmuetze.de《Sliding block puzzles》的公开分析一致；
- **引擎一致性**：以 BFS 最优解（捷足先登 47 步）生成输入脚本驱动
  headless 实机，逐格复现并到达结算画面（用 47 步・最少步达成）；
- **无效推 / 悔棋 / 重开 / 前后关卡切换**：均以 `--script` 输入脚本
  headless 验证（悔棋步数回退、空栈无效音、关卡重载正确）；
- **字集**：源码全部非 ASCII 字符均在固件字集（spec/charset.txt）内；
- **headless**：400 帧零 Lua 错误、无超预算提示。
