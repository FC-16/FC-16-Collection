# 2048 · FC-16

经典 2048 滑动合并游戏的 FC-16 移植：4×4 棋盘上方向键整行整列滑动，
相同数字相撞合并翻倍，每张牌每次移动至多合并一次；每次有效移动后随机
空格生成新牌（90% 为 2、10% 为 4）。得分即每次合并产生数值之和，
达成 2048 触发胜利演出并可继续挑战更高数字。

## 规则与实现

| 项目 | 实现 |
|---|---|
| 滑动 | 逐线「靠墙压缩 + 单次合并 + 再压缩」；同一行 `[2,2,4]` 左移得 `[4,4]` 而非 `[8]`，并入后的牌当步不再连锁 |
| 生成 | 仅在新牌生成时消耗 `rnd`（空格均匀抽取 + 90/10 数值），演出抖动全部取自帧计数——同 seed 同输入逐位一致（SPEC §7.2） |
| 判定 | 合并落地后检查：有空格或相邻同值即可继续；达成 2048 一次性胜利演出（Ⓐ 继续）；无路可走进失败画面（Ⓑ 可悔棋复活） |
| 计分 | 合并即累加该次翻倍值；最高分实时 `dset(0)` + `fflush()` 持久化，Select 的音乐开关存 `dset(1)` |
| 撤销 | 每次有效移动前压入 3 步快照栈，Ⓑ 弹出完整恢复局面与得分；空栈时提示并轻响 |

## 演出与音频

- 滑动 8 帧 ease-out 缓动，被并入的目标牌同样先滑到位再接收并入者；
  合并落地弹跳放大 + 飘字 `+N`，新牌半格放大淡入。
- 数值 → 外观全部查表（SPEC §2.2 固定色号，无色号算术）：2/4 浅色系、
  8–64 暖橙、128–512 红 / 品红、1024 紫、2048 金色配旋转十字星、
  4096+ 青色。牌面数字为 3×5 像素字模按位数取尺寸（4 位 39px 恰容于 44px 格）。
- ≥128 合并喷发金色粒子（黄金角确定性散布），≥512 震屏；
  512 / 1024 首次达成弹出里程碑横幅；2048 金色射线旋转 + 彩带庆祝。
- SFX 与轻量 BGM（A 小调四小节循环：ROUND 旋律 / TRIANGLE 琶音 / BASS
  三声部，Pattern BEGIN/END 回环）全部由 `_init` 程序化写入 SFX 与
  PATTERN 区；合并音效音高随数值档位升高，高档附加三度 / 五度 / 八度和音。

## 操作

| 键 | 功能 |
|---|---|
| ⬅⬆⬇➡ | 滑动（键盘 WASD；动画中按下会缓冲到下一步） |
| Ⓑ | 撤销最近一步（至多 3 步，失败画面下可悔棋复活） |
| Start | 标题开始游戏 / 对局中重开 |
| Ⓐ | 标题开始 / 胜利后继续挑战 / 失败后重开 |
| Select | BGM 开关（偏好持久化） |

## 构建与运行

```bash
cargo run -p fc16-tools --bin fc16mk -- --name "2048" --author "FrostMiKu" \
  --version 1 --save-id 2048 --code demo/2048/2048.lua --cover 80 \
  --out demo/2048/2048.fc16 --png demo/2048/2048.fc16.png
cargo run -p fc16-host -- demo/2048/2048.fc16
```
