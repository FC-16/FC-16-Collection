# 俄罗斯方块 · FC-16

经典拼块下落游戏。10×20 井、标准七种方块与 7-bag 随机袋，完整实现
简化踢墙旋转、幽灵落点、暂存换块、三格预告、软硬降计分、触底锁定延迟
与消行动画。精灵表与全部 SFX/MUSIC 数据由 `_init` 程序化 poke 写入，
卡带不携带二进制资产。

## 玩法与规则

| 项 | 实现 |
|---|---|
| 随机袋 | 7-bag：袋子摸空才重新洗牌，每 7 块内七种各出现一次 |
| 旋转 | 每块 4 旋转态，n×n 矩阵纯旋转 + 统一踢墙偏移表（含 ±2 覆盖 I 贴壁） |
| 幽灵落点 | 当前方块直落投影，外圈描边 + 稀疏抖动填充 |
| 暂存 | Ⓧ 暂存换块，每次落锁后刷新（不可用时显示空心样式） |
| 预告 | 右栏三格预告，下一块带高亮框 |
| 计分 | 1/2/3/4 行 = 100/300/500/800 × 等级；软降 +1/格、硬降 +2/格 |
| 等级 | 1 + 已消行数 ÷ 10；下落间隔 `max(2, 60×0.82^(等级-1))` 帧 |
| 锁定延迟 | 触底 30 帧后锁定，移动/旋转可重置（上限 15 次） |
| 消行动画 | 整行闪白，随后由中心向外逐列碎裂为粒子；四消附射线庆祝与震屏 |
| 收场 | 结束时棋盘由底向上灰化，浮出分数 / 最高分结算面板 |
| 存档 | 最高分与音乐开关经 `dset`/`dget` 持久化，落锁与结束时 `fflush` |

视觉：井居左配斜面金属框，右栏信息面板（暂存 / 预告 / 分数 / 等级 /
行数 / 最高）；七种方块各用 §2.2 固定色表中一个色系（I 青、O 黄、T 紫、
S 绿、Z 红、J 蓝、L 橙），方块由烘焙精灵绘制，带高光、暗边与深色外圈的
立体质感；标题画面有程序化落块背景与彩色大标题。

音频：14 条游戏音效（移动 / 旋转 / 软降 / 硬降 / 锁定 / 消行 / 四消三通道
庆祝 / 升级 / 结束 / 开始 / 暂停 / 暂存）+ Korobeiniki（俄罗斯民谣，公有
领域）A+B 双段 16 小节循环 BGM：旋律（ROUND）、琶音垫（TRIANGLE）、
贝斯（BASS）与鼓组四声部，每小节一条 32 步 SFX，经 16 行 MUSIC 以
LOOP_START/LOOP_BACK 回环；Select 随时开关。

## 操作

| 键 | 功能 |
|---|---|
| ⬅ ➡ | 左右移动（按下走一格，按住约 1/6 秒后 DAS 连发） |
| ⬆ / Ⓐ | 顺时针旋转 |
| Ⓑ | 逆时针旋转 |
| ⬇ | 软降（按住，+1 分/格，贴地加速锁定） |
| Ⓡ | 硬降（+2 分/格，立即锁定） |
| Ⓧ | 暂存 / 换块 |
| Start | 暂停 / 继续（暂停页附完整按键表） |
| Select | BGM 开关（持久化） |

结束画面 Ⓐ 再来一局、Start 回标题。

## 构建与运行

```bash
cargo run -p fc16-tools --bin fc16mk -- --name "俄罗斯方块" --author "FrostMiKu" \
  --version 1 --save-id tetris --code tetris/tetris.lua --cover 30 \
  --out tetris/tetris.fc16 --png carts/tetris.fc16.png
cargo run -p fc16-host -- tetris/tetris.fc16
```

headless 验证（封面取第 125 帧标题画面；headless 不带 `--seed` 时每 run
随机种子，复现请显式传 `--seed`）：

```bash
cargo run -p fc16-host -- tetris/tetris.fc16 --frames 400 --seed 1 \
  --screenshot out.png --wav out.wav
```
