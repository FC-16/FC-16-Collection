# 愤怒的小鸟 · FC-16

致敬弹弓物理破坏玩法：拉弓发射小鸟，用撞击冲量拆毁木、石、冰结构，
消灭全部小猪即可过关。美术与音乐均为原创致敬风格，物理使用 SPEC §10
内置确定性 2D 物理（AABB + 圆，Q16.16 定点）。

## 玩法

- **弹弓发射**：Ⓐ 按住拉弓，方向键 ⬅➡ 调角度（10–80 度）、⬆⬇ 调力度；
  拉弓时显示弹道预测点、力度条与皮筋拉伸，松开 Ⓐ 发射，Ⓑ 取消。
- **剩余小鸟**在弹弓左侧排队；打光且猪未清零即失败。
- **破坏与连锁**：撞击冲量超过材料耐久即破坏，碎裂粒子 + 分数；
  结构倒塌、落石压猪、炸药桶链爆均可连锁。
- **炸药桶（TNT）**：受足够冲量后延时 3 帧爆炸，半径 54px 内受径向冲量
  与伤害，可隔墙杀伤掩体中的猪。
- **计分**：材料破坏得分 + 灭猪高分（5000）+ 过关时每只剩余鸟 10000；
  按分数阈值评 1–3 星，星级与最佳分逐关存档，过关解锁下一关。
- **慢动作**：消灭最后一只猪时白闪 + 减速演出。

## 材料与伤害

撞击冲量 = 接近速度 × 有效质量（动碰静取自身质量，动碰动取约化质量）；
低于 60 px/s 的接触（静置沉降）不产生伤害。

| 材料 | 耐久 | 质量 | 摩擦 | 破坏分 | 特性 |
|---|---|---|---|---|---|
| 木 | 100 | 面积 × 1.0 | 6 | 500 | 满力直击可一发破坏 |
| 石 | 260 | 面积 × 2.2 | 6 | 800 | 小鸟直击无法破坏，靠倒塌与 TNT |
| 冰 | 45 | 面积 × 0.5 | 1（滑） | 300 | 几乎一碰即碎 |
| 猪 | 30 | πr²/256 | 4 | 5000 | 直接命中、落石或爆炸消灭 |
| TNT | 22 | 0.8 | 5 | 1000 | 冲量触发，半径 54 爆炸（伤害 320×衰减） |

小鸟：半径 6、质量 0.45、弹性 0.15（砸穿而非弹开）、发射速度 140–430 px/s。

## 操作

| 键 | 功能 |
|---|---|
| Ⓐ | 按住拉弓，松开发射；界面/结算确认 |
| 方向键 | 拉弓时调角度（⬅➡）与力度（⬆⬇）；选关导航 |
| Ⓑ | 取消拉弓；返回 |
| Start | 游戏中菜单（继续/重开/选关）；标题进选关 |
| Select | 音乐开关（BGM 三声部小循环，ch4-6） |

音频：弹弓吱呀、发射嗖声、木/石/冰三音色撞击与破坏、猪 popped、
TNT 爆炸、过关/失败旋律、星星音 — 全部由 `_init` 程序化写入 SFX 区。

## 构建与运行

```bash
cargo run -p fc16-tools --bin fc16mk -- --name "愤怒的小鸟" --author "FrostMiKu" \
  --version 1 --save-id angrybirds --code demo/angrybirds/angrybirds.lua \
  --cover 95 --out demo/angrybirds/angrybirds.fc16 \
  --png demo/angrybirds/angrybirds.fc16.png
cargo run -p fc16-host -- demo/angrybirds/angrybirds.fc16
```

存档槽位：`dset(i)` 第 i 关星级（1–10）、`dset(10+i)` 最佳分、`dset(40)` 音乐开关。
