# 吃豆人 · FC-16

迷宫追逐 demo 卡带：28×28 格经典尺度迷宫（8px/格，224×224 居中于 256×256），
四鬼按经典行为规则分工追捕，散/逐模式交替，能量豆惊恐反杀，水果奖励与关卡递进。
迷宫骨架（四角能量豆、中央鬼屋、左右隧道）致敬街机原作的事实结构；
精灵、配色、音效与全部旋律为本卡带原创，不逐像素照搬原作美术。

## 规则

| 项目 | 值 |
|---|---|
| 豆 / 能量豆 | 10 分 / 50 分（全迷宫 234 豆 + 4 能量豆） |
| 吃鬼连击 | 200 / 400 / 800 / 1600（每次能量豆重置连击） |
| 水果 | 吃掉 70 与 170 颗豆时出现在鬼屋下方，限时约 9 秒 |
| 水果序列 | 樱桃100 → 草莓300 → 橘子500 → 苹果700 → 西瓜1000 → 星星2000 → 铃铛3000 → 钥匙5000（按关卡递进，第 8 关后循环） |
| 命 | 初始 3 条，10000 分加 1 条 |
| 通关 | 豆吃清后迷宫闪白换关，速度按关卡微增、惊恐时间递减 |
| 隧道 | 第 14 行左右穿越；鬼在隧道内减速一半 |
| 存档 | 最高分与音乐开关（Select 切换）持久化 |

## 鬼 AI

四鬼共享同一套网格寻路：每到格心，从「不回头」的可行方向中选
**下一格到目标格欧氏距离最小**者，同距按经典优先序 上＞左＞下＞右；
惊恐时改为随机选向。散/逐计时为 7s-20s-7s-20s-5s-20s-5s-∞，
模式切换与吃能量豆时全场掉头；惊恐期间散/逐计时冻结。
鬼屋按豆数依次放鬼（平琪 0 / 印琪 30 / 克莱德 60，第 2 关 0/15/50，第 3 关起全 0），
另有 4 秒无豆超时兜底。眼睛回巢走格心寻路至门上方，穿门、落槽、复活出屋。

| 鬼 | 颜色 | 逐鬼目标 |
|---|---|---|
| 布林奇 | 红 | 吃豆人所在格（直追） |
| 平琪 | 粉 | 吃豆人前方 4 格（预判埋伏） |
| 印琪 | 青 | 以吃豆人前方 2 格为支点、对布林奇位置向量翻倍（侧翼包抄） |
| 克莱德 | 橙 | 距吃豆人超过 8 格时直追，否则回自己的散点角（近了就跑） |

散点角：布林奇右上 (25,0)、平琪左上 (2,0)、印琪右下 (25,27)、克莱德左下 (2,27)。
另实现经典「禁上行区」：第 11、22 行的 12-15 列，逐/散模式下鬼不得在此向上拐
（惊恐与眼睛不受限）。

速度（px/帧，60Hz）：吃豆人 1.25 × 关卡系数（每关 +4%，上限 +18%）；
鬼 = 吃豆人 × 0.90；惊恐鬼 × 0.55；隧道内 × 0.5；眼睛固定 2.3。

## 操作

| 键 | 功能 |
|---|---|
| ⬅➡⬆⬇ / WASD | 移动（格心转向缓冲，反向即刻掉头） |
| Ⓐ / Start | 标题开始游戏；游戏中 Start 暂停 |
| Select(Tab) | 背景音乐开关（存档记忆） |

音频：吃豆双音交替、惊恐警报循环、吃鬼上冲、死亡下滑、水果、加命、
开场小旋律、过关闪屏，全部由 `_init` 程序化写入 SFX 区；
BGM 为原创 A 小调四小节行进（Am-F-G-E），旋律/贝斯/琶音三声部 MUSIC 行回环，
占用 ch5-7，事件音效固定在 ch0-4。

## 构建与运行

```bash
cargo run -p fc16-tools --bin fc16mk -- --name "吃豆人" --author "FrostMiKu" \
  --version 1 --save-id pacman --code pacman/pacman.lua --cover 30 \
  --out pacman/pacman.fc16 --png carts/pacman.fc16.png
cargo run -p fc16-host -- pacman/pacman.fc16
```

无二进制资产：墙瓦（16 种连接掩码）、水果（8 种）由 `_init` 逐像素烘焙进精灵表，
吃豆人与鬼为运行时程序化绘制（圆制三角裁嘴、逐行穹顶裙摆）。
