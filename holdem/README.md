# 德州扑克 ・ FC-16

无限注德州扑克（No-Limit Texas Hold'em）。4 或 6 人椭圆牌桌，1–4 人热座 +
AI 补位；庄家钮轮转、小盲/大盲、四轮下注（翻牌前 → 翻牌 → 转牌 → 河牌）、
7 选 5 摊牌与分层边池结算全部完整实现。无任何二进制资产：牌面（3×5 点数 +
5×5 花色迷你字形）、绿毡牌桌、筹码、SFX 与 BGM 全部由 `_init` 按 SPEC §5.2
布局程序化写入。

## 规则

- 标准 52 张牌，无王。每人初始 1000 筹码；牌桌总人数 4 或 6，破产者淘汰，
  仅剩一人时结算终局。
- **盲注制**：起始小盲/大盲 10/20，庄家钮每手向下一存活座位轮转；**每 8 手
  盲注翻倍**（20/40 → 40/80 → …），强制进入残局。破产边缘不足额盲注按
  全下处理。
- **四轮下注**：每轮自庄家钮后首位开始顺时针行动，直到下注平衡（所有人
  跟平且均已行动）。动作：弃牌 / 过牌（无人下注时）/ 跟注 / 加注 / 全下。
- **最小加注**：加注增量不得低于上一个下注/加注的增量（翻牌前最小加注为
  一个大盲）。**不足额全下**（all-in 金额高于跟注额但不足一个完整加注）不
  重开已行动玩家的加注权——他们只能跟注或弃牌，未行动者仍可完整加注。
- **边池（side pot）**：多人不等额全下时按投入分层结算：取当前未弃牌玩家
  的最小投入为第一层，所有玩家（含弃牌者的死钱）各贡献该层高度，未弃牌
  且投入达到该层高度者有资格争夺；余量进入下一层，逐层向上。每层由该层
  资格者中的最佳牌型独得或平分（零头给庄家钮后最早的可赢座位）。未被跟
  注的加注差额通过"仅剩一人的顶层"自然退还。
  例：A 全下 300、B 跟 300、C 跟 800 → 底层 900 由三人争夺，顶层 500 只有
  B、C 有资格。
- **摊牌**：河牌圈下注平衡后，未弃牌者依次亮牌，7 张牌（2 底牌 + 5 公共
  牌）枚举 C(7,5)=21 种组合取最佳：高牌 / 一对 / 两对 / 三条 / 顺子（含
  A2345 轮子顺）/ 同花 / 葫芦 / 四条 / 同花顺 / 皇家同花顺；同型按决胜链
  （kicker）逐一比较。获胜五张牌以金框高亮。
- 全员弃牌则最后下注者直接收池（不亮牌）；所有人全下时立即摊牌，剩余公共
  牌逐街发完（全下 run-out）再分层结算。
- 平分池底数整除，零头给按钮后最早座位；筹码守恒（6000/4000 总量恒定）。
- 存档：`dset` 槽 0 = 累计手数、1 = 人类累计胜局、2 = 人类最佳单池、
  3 = 音乐开关（`fflush` 落盘）。

## AI 三档策略（确定性启发式）

| 难度 | 风格 |
|---|---|
| 简单 | 松散被动：几乎只跟注/过牌（加注率约 1%），偶尔随机弃牌，强牌也极少加注 |
| 普通 | 起手牌按 Chen 公式估值分组行动（≥8-9 加注入池、面对加注按底池赔率跟/弃）；翻后用成牌强度（顶对/超对/暗三等分层）+ 听牌数（同花 9 / 两端顺 8 / 卡顺 4，按 4&2 法则折算胜率）对照底池赔率决定跟注/弃牌，强牌下注约半池至 2/3 池 |
| 困难 | 在普通基础上：位置感知（按钮/关煞位放宽开局与偷池阈值、后位 3bet 轻加注）、下注尺寸变化（后位小加注入池、湿牌面保护性大注、价值注随牌力与对手进攻度调整）、翻前持续下注（heads-up 时约 75%）、听牌半诈唬加注、强牌慢打陷阱、对手进攻度修正弃牌线、短码（≤6BB）推/弃模式 |

所有 AI 动作统一经合法动作归一化入口提交（非法请求自动收敛为最近的合法
动作），并对加注额做 [最小加注, 全下] 钳制，保证永不非法行动。

## 操作

| 键 | 功能 |
|---|---|
| ⬅ ➡ | 选择动作（弃牌 / 过牌・跟注 / 加注 / 全下） |
| ⬆ ⬇ | 调整加注档位（最小 / ¼ 池 / ½ 池 / 满池 / 全下） |
| Ⓐ | 确认动作；标题开局；结算后下一手；终局返回标题 |
| Ⓑ | 快捷选中弃牌（再按 Ⓐ 确认） |
| Ⓧ | 按住加速（AI 思考与演出 4 倍速） |
| Select | 音乐开关（BGM：贝斯 + 管风琴切分，C-Am-Dm-G 循环） |
| Start | 同 Ⓐ 继续 |

标题画面 ⬆⬇ 选行、⬅➡ 调整：桌上人数（4/6）、人类玩家（1–4）、AI 难度。

**热座隐私**：人类玩家 >1 时，轮到某人类行动前显示全屏遮罩（仅座位、筹码
与底池，不含任何手牌），按 Ⓐ 亮牌后才显示其底牌与动作菜单；行动结束进入
下一位玩家时手牌立即隐藏。单人模式常显自己底牌（座位小牌 + 底栏大牌）。

底栏状态行实时提示当前成牌（翻牌前显示"对X/高X"，翻牌后显示最佳牌型名），
供快速决策参考。

## 构建与运行

```bash
cargo run -p fc16-tools --bin fc16mk -- --name "德州扑克" --author "FrostMiKu" \
  --version 1 --save-id holdem --code demo/holdem/holdem.lua --cover 70 \
  --out demo/holdem/holdem.fc16 --png demo/holdem/holdem.fc16.png
cargo run -p fc16-host -- demo/holdem/holdem.fc16
```

开发期验证参考：`--frames 400 --screenshot` 走查标题/牌桌；用 `--script`
注入周期性「← + Ⓐ」（弃牌/继续）并按住 Ⓧ 即可让 AI 长跑完整对局、淘汰与
终局结算（数千帧零错误，筹码总量恒定）。
