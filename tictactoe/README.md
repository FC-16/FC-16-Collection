# 井字棋 · FC-16

经典井字棋 + 终极井字棋（9 宫嵌套变体）演示卡带。纸面棋盘、手绘描边风
X / O 棋子与全部音效均由 `_init` 程序化生成，卡带不携带二进制资产。

## 模式

| 模式 | 说明 |
|---|---|
| 双人对战 | 同屏轮流，蓝 X 先手 |
| 人机对战 | 三档 AI + 先手选择（玩家先 / 电脑先 / 观战演示） |
| 终极棋局 | 9×9 嵌套变体，可选双人或人机（人机同样三档 + 先手选择） |

## AI

**经典井字棋**

- **简单**：能赢就赢 → 必堵一手 → 其余随机。单威胁必堵（挡得住明枪），
  但不识别双威胁（fork），被"中心 + 双角"一类构造一击即穿；
- **普通**：赢 → 堵 → 中心 → 对角 → 角 → 边 优先级启发。挡得住所有单威胁，
  同样会输给双威胁；
- **困难**：**完美 minimax**（negamax + 全局面记忆化 + 同分最优随机）。
  井字棋在完美对局下必为平局，因此困难 AI 不可战胜——玩家完美应对就是平局，
  犯错即被惩罚。搜索以协程分帧执行（每 700 节点让出一次），并跨局共享
  记忆化表，全程不超单帧 20 万指令预算。

**终极井字棋**（启发式，非穷举）

- 简单 = 合法着随机；普通 = 启发；困难 = 启发 + 一步终胜防察。
  启发优先级：直接终胜 ＞ 不送对手一步终胜（仅困难）＞ 小宫取胜 / 堵宫 ＞
  不把对手送进"可任意选"或"一步成宫"的宫 ＞ 中宫与中格位置分。
  终极变体状态空间大，困难档不保证不可战胜。

## 规则（终极井字棋）

9 个 3×3 小宫排成 3×3；落子所在的小格编号即对手下一手的**行棋宫**；
被指向的宫已被占领（成三连）或已满时，对手**任选**宫位。小宫三连即占领
该宫，三个宫成线即获胜；全部宫定局而无连线为平局。顶栏点阵图实时指示
下一手的目标宫（闪烁 = 当前指宫）。

## 操作

| 键 | 功能 |
|---|---|
| ⬅➡⬆⬇ | 移动光标（按住自动重复） |
| Ⓐ | 落子 / 标题确认 |
| Ⓑ | 悔棋（人机退两手；思考中按 Ⓑ 取消思考并退玩家那手） |
| Start | 重开一局 / 标题开始 |
| Ⓨ | 回标题 |
| Select | BGM 开关（存档记忆） |

标题菜单行数随模式动态变化：⬅➡ 调值、⬆⬇ 选行、Ⓐ 开始。

## 战绩存档

`dset + fflush` 持久化（存档槽 0–8 + 音乐开关槽 9）：双人记 X 胜 / O 胜 /
平；人机记胜 / 负 / 平；终极记先手胜 / 后手胜 / 平（观战演示局不计入）。
标题与对局底栏轮换显示。

## 音频

X 方波低叩 / O 铃铛高叩双音色落子、悔棋、胜利 / 平局旋律、按钮音、
终极得宫音，以及四小节回环的原创 BGM（旋律 ROUND + 贝斯 BASS，
Select 开关）。

## 构建与运行

```bash
cargo run -p fc16-tools --bin fc16mk -- --name "井字棋" --author "FrostMiKu" \
  --version 1 --save-id tictactoe --code demo/tictactoe/tictactoe.lua \
  --cover 110 --out demo/tictactoe/tictactoe.fc16 --png demo/tictactoe/tictactoe.fc16.png
cargo run -p fc16-host -- demo/tictactoe/tictactoe.fc16
```

headless 验证（400 帧零错误 + 截图）：

```bash
cargo run -p fc16-host -- demo/tictactoe/tictactoe.fc16 --frames 400 \
  --screenshot demo/tictactoe/_chk.png
```

（含穷举最优子树 8550 节点全部取值的离线证明）；简单 AI 漏堵以
"X 中心 + 双角双威胁"脚本局演示（AI 堵住一端、漏掉另一端落败）。
