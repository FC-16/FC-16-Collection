# 小丑牌（balatro-gba 移植版 · FC-16）

以 [GBALATRO/balatro-gba](https://github.com/GBALATRO/balatro-gba)（GBA 平台的 Balatro
同人 demake）为蓝本的 FC-16 移植：52+1 张小丑、13 种牌型、8 个 ante、30 个盲注 token、
开局选牌组/种子、商店、结算与选项，交互与演出对齐 GBA 版语义。
**仅作研究学习用途的本地移植，不随项目对外发布；Balatro 版权归 LocalThunk/Playstack。**

## 与 GBA 版的对应关系

- **内容**：小丑名单、稀有度与定价、牌型基础数值、盲注 ante 目标表（300→50000，ante 1 小/大/Boss = 300/450/600）、
  经济（奖金 $3/$4/$5，剩余手牌 ×$1，利息 min($/5, 5)）、商店（2 货位、重掷 $5 递增）、
  Boss 不重复抽取、ante 8 的 Boss 为 Showdown——均按 GBA 版语义。
  GBA 版 Boss 效果未实现（目标一律 ×2），移植保持一致。
- **牌组**：GBA 选牌界面只显示六种牌组的效果文案、逻辑未接线（选择仅影响牌背）；
  移植按其文案实现——红 +1 弃牌/轮、蓝 +1 出牌/轮、黄开局 +$10、
  绿结算为剩余出牌 ×$2 + 剩余弃牌 ×$1 且无利息、黑小丑槽 +1 且出牌 -1/轮、
  彩手牌上限 +2 且小丑槽 -1。小丑槽与手牌上限由牌组派生，不入存档。
- **交互**：A 选牌/确认（按住 A + ←/→ 交换手牌与小丑，方向参与即交换；纯点按松开时选牌）、B 全取消、
  LB 出牌/卖小丑、RB 弃牌、LT 按点数排序、RT 按花色排序。
  商店光标分三行——货位（左右两格）/ 重掷·离开 / 持有小丑——方向键严格按屏幕方位移动：
  横向在行内环绕、纵向跨行并尽量保持列，已售出的货位横向跳过、纵向不进入；
  聚焦项的说明面板常驻（无需按住 B）。全部按键提示经 `btnicon()`/固件图标渲染。
  对局左栏把盲注图标与名称并排一行，省下的高度分给分数、筹码/倍率与操作按钮各行，不再拥挤。
- **差异**：GBA 的 240×160 UI 改为 FC-16 256×256 原生重排（12px 中文固件字体）；
  商店重排为三行网格——货位两格（稀有度描边的价格牌，售出后留空位不重排）、
  重掷/离开两钮与货位同列对齐、持有小丑一行居中并显示空槽容量，屏幕下方常驻说明面板；
  GBA 背景烘焙图不再使用，仅取其桌面仿射纹理作 MAP1 底纹；音频沿用本 demo 原生
  重制的芯片音序；选项菜单仅保留"游戏速度 1–4"（GBA 的音量/卡面选项无平台 API 或
  依赖独立美术）；续局在 FC-16 上真正可用（GBA 版的 Resume 未接通）。

## 操作

| 按键 | 作用 |
|---|---|
| 方向 / WASD | 移动选区（手牌行 / 小丑行），按住后每 4 帧重复一格 |
| A (J) | 选牌 · 确认 · 按住 + ←/→ 交换（重复节奏同方向键） |
| B (K) | 取消全选 · 返回 |
| LB (Q) | 出牌 · 小丑行/商店卖小丑 |
| RB (O) | 弃牌 |
| LT (E) | 手牌按点数排序 |
| RT (O) | 手牌按花色排序 |

存档按卡带头 save_id `balatro` 归档（`save/load` 结构化 JSON：`{speed, run}`）：选项与对局
（ante/轮次/金钱/盲注/已击败 Boss 池/持有小丑及持久状态/种子/统计）在开局与
离开商店时落盘，主菜单"继续挑战"读档续局；读档以
`SRAND_U32(seed + ante×7919 + round)` 重建随机序列（FC-16 无法读出宿主 PCG32 内部状态，
属记录在案的功能性偏差）。

## 玩法内容

- **牌组 6 种**：红/蓝/黄/绿/黑/彩（效果见"对应关系"），决定每轮出牌/弃牌数、
  手牌上限（彩 10）、小丑槽（黑 6、彩 4）与开局金钱（黄 $14）。
- **牌型 13 种**：高牌 5/1 → 同花五条 160/16（GBA `HAND_BASE_VALUES`，无星球升级）。
  A 可作 A-2-3-4(-5) 低位；四指小丑使顺子/同花降至 4 张，捷径小丑允许隔 1 点数；
  只有构成牌型的牌计分。
- **小丑 53 张（id 0–52）**：与 GBA 注册表一一对应——花色/牌型条件系、重触发系
  （袜与靴、吊人、黑客、暮光、气泡水）、复制系（蓝图复制右侧、头脑风暴复制最左）、
  规则改写系（四指、捷径、似人）与经济系（商业卡、预留车位、公牛、系绳）。
  稀有度 roll 70/25/5，只从未持有者中抽取；卖价为进价一半。
- **盲注 30 个**：小盲/大盲 + 23 Boss + 5 Showdown（ante 8），目标 = ante 基数
  ×1/×1.5/×2；小/大盲可跳过（无奖励，GBA 语义）；打完 ante 8 Boss 通关。

## 资产管线

`gen_assets.py` 一次生成全部数据段；GBA 原始 PNG 在 `gba/`（研究学习用途的本地副本）：

- `sprites.bin`：512KiB，8bpp 64 色。**32×32 精灵按"2 行瓦片带"放置**（每带 32 格放
  8 张，占 t、t+1、t+16、t+17——与 `spr(t,2,2)` 的 16 瓦片/行组合规则一致）：
  - 牌面 `0..223`：`band_tile(0, 花色×13+点数)`（♦♣♥♠ × 2..A，源 `deck_gfx.png` 13×4）
  - 牌背 `224..255`：`band_tile(224, 牌组号)`（6 种，源 `decks_face_down_gfx.png`）
  - 小丑 `256..479`：`band_tile(256, id)`（53 张，源 `joker_gfx0..17.png`）
  - 盲注 `480..607`：`band_tile(480, 盲注号)`（SMALL/BIG + 23 Boss + 5 Showdown）
  - 桌面仿射纹理单瓦片 `608..`（`affine_background_gfx.png`）
- `maps.bin`：256KiB。plane0 未使用（全 0）；plane1 烘焙桌面仿射纹理，仅对局屏绘制。
- `sfx.bin`（128×144B）/ `waveforms.bin`（8×80B）/ `music.bin`（2080B）/ `icon.bin`：原生重制音频与图标。
- 全部像素经 **SPEC §2.2 表格顺序的 FC-16 64 色最近邻映射**；不透明近黑强制 →色 1
  （色 0 是透明色，只留给 alpha 镂空）。

## 构建与验证

```bash
python3 tools/build_all.py balatro
../FC-16/target/debug/fc16 balatro/balatro.fc16
```

代码按构建期静态 require 拆为模块：`main.lua` 入口 + `const / content / input / ui /
hand / score / run / blindsel / round / shop / menus / save`，跨文件状态经全局表共享；
清单 `fc16.project.json` 声明卡带头参数（save_id、封面帧、资源段），
`fc16-tools project build` 递归组装为单一 Lua chunk 写入卡带。

headless 回归（`--seed` 固定；按键为 §6 按钮名，`--save` 注入 JSON 存档只读）：

```bash

../FC-16/target/debug/fc16 balatro/balatro.fc16 --seed 1 --frames 520 --script <(cat <<'EOF'
60 key a
68 key -
100 key a
108 key -
150 key a
158 key -
300 key a
304 key -
330 key right
334 key -
360 key a
364 key -
430 key lb
434 key -
EOF
) --screenshot /tmp/balatro_round.png
# 30s 音频：BGM + 选牌/出牌/计分音效
../FC-16/target/debug/fc16 balatro/balatro.fc16 --seed 1 --frames 1800 --wav /tmp/balatro.wav
```

已核对：标题/主菜单/开局设置（主菜单已分流"新的对局/继续挑战"，设置屏为
牌组/种子/开始三行表单、不再重复主菜单入口，"继续挑战"直接读档进盲注选择；
六牌组说明单行/两行均不压控件；种子键盘 4×10 全 36 字符，A 进入编辑、
B 或顶行向上完成，光标按可见格子行列移动）/盲注选择与跳过/对局与计分演出（翻牌、筹码倍率跑条、
乘算滚动、震屏）/结算面板（奖金、剩余手牌、利息；绿牌组为剩余出牌 ×$2、
剩余弃牌 ×$1、利息（无））/商店（三行光标位移与行列对应、购买后自动移到仍有货的一格、
空货位不可达、出售、重掷、说明面板常驻，纵向节奏 8px 等距）/失败与胜利
结算（最佳单次、最常牌型、种子复用）/选项（游戏速度）/存档注入
读档续局/30s WAV 全程有声无削波/左栏各长度文案不溢出不重叠。
对局左栏已重排：分数/筹码/倍率框标签外置、描边随语义配色（中性/天蓝/红），
手牌容量与牌库计数并排于对局区右上。
牌组效果逐项核对：红弃牌 5、蓝出牌 5、黄 $14、黑出牌 3·槽 6、彩手牌 10·槽 4；
计分跑条落账已修复为精确总分（此前版本每手虚增约 15/16 的近似增量）；
6 小丑行与 6 空槽行按可用宽度自适应步进，不越左栏不出屏；
多文件拆分后与单文件版逐像素一致。

## 移植取舍（实现说明）

- **boss 效果**：GBA 版仅实现 ×2 目标倍率（Wall ×4 等属其"未做的 effect 部分"），
  移植保持一致；30 个盲注的美术与命名完整保留。
- **重触发模型**：卡计分结束（ce）钩子累计次数后重放"筹码 + cs"一段，不重放翻牌与
  ce 本身，避免重触发递归；气泡水的剩余次数在整手结算（hs）时扣减，归零销毁。
- **复制链**：蓝图/头脑风暴在触发点解析复制源（跳过复制体），演出浮字跟随复制体
  位置；两者自身无独立效果。
- **存档**：GBA 版 Resume 未接通，本移植接通；随机序列重建采用 seed+进度 派生
  （见上），与 GBA 的 rng_info 快照语义不同。
- **GBA 特性未移植**：灵动分辨率/affine 旋转动画、高对比与 more-readable 卡面
  （独立美术）、GBA 键位彩蛋、游戏内 README。
