# 小丑牌（Balatro · FC-16 移植版）

以 FC-16 原生 Lua 方言从零实现的 Balatro 式扑克肉鸽：把一副 52 张的标准牌组打出
筹码 × 倍率的组合，击败逐 ante 递增的盲注目标。玩法、演出与经济系统按原作语义完整
移植，视觉与音频为 FC-16 原生重制（固定 64 色、芯片音序器），不依赖原作任何资产。

## 玩法内容

- **盲注流程**：每 ante 三战（小盲注 ×1 / 大盲注 ×1.5 / Boss ×2），目标分数按原作
  ante 基数表递增（100 → 50000，无尽模式最高 530 兆）；击败盲注 8 的 Boss 通关，
  可继续无尽模式（ante 9–16）。
- **16 种 Boss 盲注**：钩子（出牌后夺牌）、高墙（×4 目标）、针筒（1 次出牌）、水门
  （禁弃牌）、四花色之头（对应花色全部失效，失效牌灰化）、镣铐、心灵（必须 5 张）、
  邪眼（牌型不可重复）、独口（锁定牌型）、燧石（基础减半）、手臂（降级）、尖牙、巨蛇。
- **52 张小丑**：花色/牌型条件系、累计成长系（绿小丑、搭公车、方块小丑、忠诚卡）、
  概率系（太空小丑、血石、香蕉）、经济系（商业卡、无面小丑）、规则改写系（四指、
  涂抹、哑剧、袜子与戏剧）与稀有系（蓝图/头脑风暴相互复制、男爵、星座、DNA、棒球卡、
  钢铁小丑）。小丑可获版次：箔（+50 筹码）/全息（+10 倍率）/多彩（×1.5）。
- **22 张塔罗**：牌面强化（富余/多重/万能/玻璃/黄金/钢铁/石头/幸运）、升阶（力量）、
  销毁（倒吊人）、复制（死神、愚者）、金钱（隐士、节制）、版次（命运之轮）、随机
  （皇帝、女祭司、审判）。需要指定牌的塔罗进入牌组选牌界面。
- **12 颗星球**：对应 12 种牌型的等级成长（基础筹码/倍率 + 每级增量按原作数值）。
- **牌型判定**：高牌到同花五条共 12 种；枚举全部打出子集取最优；A 可作 A-2-3-4-5 低位；
  万能牌并入任意花色；石头牌必计分。
- **经济**：盲注奖金 $3/$4/$5、利息每 $5 +$1（上限 $5）、黄金牌回合末 +$3、尖牙扣款；
  商店 3 货位 + 重掷（$5 递增），小丑按稀有度定价、半价出售。
- **跳过盲注**得随机标签：投资（Boss 后 +$15）、重掷免费、商店半价。

## 操作

| 按键 | 作用 |
|---|---|
| 方向键 / W A S D | 移动光标（手牌 / 小丑行 / 按钮） |
| A (J) | 确认 · 选牌（至多 5 张） |
| B (K) | 取消选择 · 返回 |
| MENU (Enter) | 出牌 · 购买 · 继续 |
| VIEW (Tab) | 弃牌 · 盲注选择处跳过 |
| Y (I) | 排序（点数/花色）· 商店重掷 |
| X (U) | 出售光标处小丑 |
| LB (Q) / RB (L) | 牌组一览 / 牌型等级一览 |

存档按卡带头 save_id `balatro` 归档（~/.fc16/saves/balatro.sav），在盲注选择、
跳过、进商店与通关时自动落盘；失败清档。

## 演出与手感

- 计分采用协程时间轴：发牌滑入、选牌悬浮抖动、出牌滑行翻转、逐张筹码/倍率跑条
  音高递进（SFX 5/6/8 为 16 步上行，经 `sfx` offset 步进触发）、×倍率震屏、
  结算数字加速滚动，全流程对应原作节奏。
- 失效牌整卡灰化（绘制期 `pal`）、版次边框多彩轮闪、小丑触发水平抖动、
  浮动数字（大字带投影）、盲注进度条蓝→金。
- 四色花色（♠黑 ♥红 ♦蓝 ♣绿）贯穿手牌、牌组一览与图标。

## 资产管线

`gen_assets.py` 一次性生成全部数据段（输出与 `balatro.lua` 内的精灵表布局注释同步维护）：

- `sprites.bin`：256×1024 精灵表。注意 FC-16 按瓦片连续存储（每瓦片 256B），画布按
  行主序绘制、导出时重排；52 张 24×24 小丑、16 个 Boss 图标、22 塔罗 + 12 星球、
  UI 图标行、BALATRO 标题字（从 `assets/font.bin` 提取固件字形 ×2 描边）。
- `sfx.bin`：128 条 × 112B。0–31 游戏音效；64–83 为 BGM 声部（低音/和弦/旋律/闭镲/军鼓）。
- `patterns.bin`：64 段 × 16B，Pattern 0–7 组成 A 小调 75 BPM 循环（0 BEGIN、7 BEGIN|END），
  运行时 `music(0, 400, 0xC7)` 占用 ch0/1/2/6/7，ch3/4/5 留给音效自动路由。
- `icon.bin`：16×16 8bpp 小丑脸。

## 构建与验证

```bash
python3 demo/balatro/gen_assets.py
cargo run -p fc16-tools --bin fc16mk -- --name "小丑牌" --author "FrostMiKu" --save-id balatro \
    --version 1 --code demo/balatro/balatro.lua --sprites demo/balatro/sprites.bin \
    --sfx demo/balatro/sfx.bin --patterns demo/balatro/patterns.bin --icon demo/balatro/icon.bin \
    --cover 45 --out demo/balatro/balatro.fc16 --png demo/balatro/balatro.fc16.png
cargo run -p fc16-host -- demo/balatro/balatro.fc16
```

## 移植取舍（实现说明）

- 精灵与音乐为 FC-16 原生重制，不搬运原作美术/音频；卡面以程序绘制（圆角矩形 +
  3×5 迷你字 + 7×7 花色点阵），标题字取自固件字体。
- 未收录原作系统：牌包/礼券、凭证、标签仅 3 种、部分依赖牌包的小丑（Vampire、
  Hologram 等）未入选；52 张小丑覆盖原作常规构筑路线。
- 无尽模式 ante > 16 后目标分数封顶于 5.3 兆（dset 定点槽与显示位数约束）。
- 商店不设消耗品栏：星球购买立即升级，塔罗立即生效（需选牌的进入选牌界面）。
