# 飞行棋 · FC-16

经典中式四色飞行棋（Ludo）卡带。256×256 屏幕内完整呈现四色对称棋盘：
四角机场、52 格环形跑道（每色 13 格，颜色沿跑道四色循环）、各色 6 格终点跑道、
中心四色三角终点广场与四条虚线飞行捷径。全部精灵、音效与 BGM 由 `_init`
程序化生成（poke 写精灵表 / SFX / PATTERN），卡带不携带二进制资产。

## 规则

完整规则（与本卡带实现一致）：

- 四名玩家（红・黄・蓝・绿）各 4 架飞机，红方先行，顺时针行进。
- **起飞**：只有掷出 6 才能将飞机从机场飞到己方起飞格（起飞不触发跳跃）。
- **再掷**：掷出 6 落子后可再掷一次；撞回敌机也奖励再掷一次（同一次移动
  两种奖励只再掷一次）。**三连六惩罚**：同一回合连续掷出第三个 6 时本回合作废
  （第三枚 6 不落子），换下家。
- **同色跳跃**：骰步落在己色格上时，跳到前方下一个同色格（+4）。
  跳跃不连环，一次移动至多跳一次。
- **捷径飞跃**：每色有一个带虚线角框与迷你飞机标记的己色飞行格（约在
  己方行程中点）。骰步恰好落在上面时沿虚线捷径直接飞跃到对面同色格（+12），
  同样不与跳跃连环。
- **撞机**：落点（含跳跃、飞跃后的落点）如有敌机，敌机全部被撞回其机场，
  落点上的己方飞机可叠放共存。
- **终点**：必须恰好掷数到达中心；多出的步数先走到中心再回退走完
  （回退只发生在终点跑道内，不会退回环形跑道）。
- **胜利**：4 架全部到达中心即夺冠。

简化与约定（相对部分实体规则）：

- 飞跃途中只撞击落点上的敌机，不扫荡沿途格子。
- 同色跳跃不得越过终点入口：`+4` 超出第 50 格（入口格）时不跳。
- 首位玩家完成后直接结算：冠军固定第一，其余三家按完赛架数、
  总行程进度排名次（不继续打完全部名次）。
- 跑道上没有绝对安全格；起飞格、终点入口同样可被撞。
- 人类玩家可以用 Ⓑ 主动放弃本次移动（ forfeit 整个回合，含未用的再掷）；
  电脑永远不会弃权。

## AI 策略

电脑玩家使用确定性加权启发式，对每个合法着法评分取最高（平局取飞机序号小者）：

| 因素 | 权重 |
|---|---|
| 恰好到达终点 | +130 |
| 每撞回一架敌机 | +80 |
| 触发捷径飞跃 | +48 |
| 起飞 | +36 |
| 触发同色跳跃 | +16 |
| 行程进度 | +0.6/格 |
| 落点被敌方 1-6 步追及 | −13/架（含敌方机场压境起飞格） |
| 终点回退浪费 | −20 |
| 落点叠己方子 | −4/架 |

评估与实际执行共用同一个 `resolve_landing()` 落点结算函数，电脑永远不会走出
与评分不一致的棋。

## 操作

| 键 | 功能 |
|---|---|
| ⬅ ➡ ⬆ ⬇ | 标题调整人类玩家数（其余座位为电脑）；对局中多机可动时选择飞机 |
| Ⓐ | 掷骰／确认移动选中的飞机／结算画面回到标题 |
| Ⓑ | 放弃本次移动（整个回合） |
| Select | 背景音乐开关（标题与对局中均可用，随存档记忆） |
| Start | 对局中回到标题（进度不保存） |

顶栏显示四家到达架数（`n/4`）、人类/电脑身份与当前行动方；骰子面板显示在
当前行动方机场中央；落点预览圈提示选中飞机的最终落格。战绩（总局数）经
`dset`/`fflush` 持久化。

## 音频

芯片音效覆盖掷骰、定格、起飞、逐格嘀嗒、同色跳跃、捷径飞跃、撞机、返航、
到达终点、再掷、三连六警告与胜利旋律；BGM 为 C 大调轻快回旋
（C・Am・F・G，ORGAN 旋律 + BASS + TRIANGLE 琶音垫，两段 Pattern 循环），
占 ch4-6（mask 0x70），游戏音效自动路由到其余通道。

## 构建与运行

```bash
cargo run -p fc16-tools --bin fc16mk -- --name "飞行棋" --author "FrostMiKu" \
  --version 1 --save-id ludo --code demo/ludo/ludo.lua --cover 40 \
  --out demo/ludo/ludo.fc16 --png demo/ludo/ludo.fc16.png
cargo run -p fc16-host -- demo/ludo/ludo.fc16
```

`--cover 40` 取标题画面第 40 帧作卡带封面。headless 验证：

```bash
cargo run -p fc16-host -- demo/ludo/ludo.fc16 --frames 400 \
  --screenshot out.png --wav out.wav
```
