# 抢滩登陆战 2002 · FC-16

致敬 Beach Head 2002 的滩头堡垒防御射击游戏。FC-16 主机没有任何内置 3D
能力，本卡带在 Lua 侧从零实现了一套完整的软件 3D 渲染管线。

## 自制 3D 管线

| 阶段 | 实现 |
|---|---|
| 几何 | 程序化盒体部件拼装模型（士兵 / 轮式装甲车 / 坦克 / 直升机 / 战斗机 / 登陆艇 / 军舰 / 补给箱 / 残骸），部件支持自转（旋翼、炮塔） |
| 变换 | 模型空间 → yaw 旋转 → 平移 → 相机空间；俯仰以视平线剪切（shear pitch）实现 |
| 投影 | 透视除法 `sx = 128 + xc/zc·F`，焦距 200px |
| 剔除 | 面片世界法线与视线点积做背面剔除 |
| 着色 | 平面着色：法线与冻结平行光点积分 4 档，查每材质手调明暗表（不做色号算术） |
| 排序 | 画家算法：实体按视深排序 + 部件按视深排序（盒体凸性保证可见面互不重叠，部件内免面片排序，trifill 内联发射） |
| 光栅化 | 每个三角形一次 `trifill`（Rust 侧光栅化），顶点 / 面片暂存全部复用 |
| 地面 | mode-7 透视纹理：逐扫描线求世界射线与地面交点，一条 `tline` 采样 4096×4096 地图纹理；海面按离岸距离渐入波浪推移 |
| 命中 | 机枪为真实 3D 射线-球判定（士兵区分头部 / 躯干）+ 距离自适应弹道磁吸（约 ±0.7° 角容差，准星压上目标时变金色收紧）；反坦克炮为无下坠直射——炮弹沿准星射线匀速直飞，落点即准星所指位置，命中大爆炸 + 半径 11 溅射（中心伤害 16，可一发掀掉坦克）。受击时屏幕边缘红闪；来袭方向弧带仅在袭击者出屏时出现（前方半球按投影方位、背后按世界方位），随视角实时换算 |

纹理、SFX、BGM、战鼓 Pattern 全部由 `_init` 程序化写入，卡带不携带二进制
资产。BGM 为 A 小调战地进行曲（贝斯 / 主旋律 / 和声垫 / 鼓四声部），乐谱用
一套 32 字符/小节的简易谱面记法编译生成。12 个小节素材按难度组成三套歌单：
第 1–2 波「滩头守备」12 小节、第 3–5 波「抢滩」16 小节（加入副歌段）、
第 6 波起「总攻」16 小节（25% 提速驱动段），循环时长 26–34 秒。

## 玩法

固守滩头堡垒，顶住一波波进攻：步兵涉水抢滩、跪射三轮后换位逼近；登陆艇
抢滩放下前舱板卸兵后倒车离岸；轮式装甲车抵近、停车放下后舱盖放出
一次步兵，随后就地机枪点射（射速高、单发伤害低），被击毁后与坦克一样留下
冒烟残骸；坦克逐渐抵近、进射程
后转动炮塔瞄准开火（伤害高、射速低），被击中会横移规避，装填完毕再次
攻击；直升机悬停投火箭，空军自第 3 波起分三型进场——**战斗机**蛇形高速掠袭
并对阵地机枪扫射、**轰炸机**沿航迹串列投下 3 弹、**运输机**（第 5 波起）飞越
阵地上空放伞兵，伞兵开伞缓降摇曳落地后加入地面战斗；军舰远程炮击；空投
补给箱回复弹药与生命。每波开场横幅预告兵力构成。

## 敌人 AI 架构

全部敌人由**表驱动状态机**驱动：每类实体一张 `AI[kind]` 表，`initial` 按出生
条件选初始状态，`states[name] = { enter, update }`，`update` 返回下一状态名；
`on_hit` 钩子实现坦克 / 装甲车受击横移。状态内约定 `e.stt`（状态帧龄）、
`e.ft`（开火计时）、`e.dead`（请求移除）。新增敌型只需添加一张状态表。

## 操作

| 键 | 功能 |
|---|---|
| ⬅ ➡ | 转向（短按微调、按住约半秒加速到全速；Ⓛ/Ⓡ 快速 90° 甩头） |
| ⬆ ⬇ | 俯仰（同样的短按微调 / 长按加速曲线） |
| Ⓐ | 机枪（10 发/秒，弹链 100 发，打空自动装填） |
| Ⓑ | 反坦克炮（范围溅射） |
| Ⓧ | 手动更换弹链 |
| Start | 暂停 |
| Select | 调试：显示每帧 VM 指令预算占用 |

受击 / 回复只在屏幕边缘显示一圈红 / 绿提示，不遮挡战场；红圈同时以
弧带 + 内指箭头标示最近一次受击的来袭方位（随视角实时换算）；云固定于世界方位，
转头时的移动全部来自视差。

## 构建与运行

```bash
cargo run -p fc16-tools --bin fc16mk -- --name "抢滩登陆战2002" --author "FrostMiKu" \
  --version 1 --save-id beachhead2002 --code demo/beachhead/beachhead.lua \
  --out demo/beachhead/beachhead.fc16 --png demo/beachhead/beachhead.fc16.png --cover 110
cargo run -p fc16-host -- demo/beachhead/beachhead.fc16
```

`game.png` / `game.wav` 为一次 2600 帧无人工干预战斗的 headless 预览。
