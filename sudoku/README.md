# 数独 · FC-16

FC-16 幻想主机上的完整数独演示卡带：三档难度、唯一解题库现场生成（分帧切片，不卡帧）、
铅笔候选、提示与冲突检查一应俱全；SFX 与 BGM 全部由 `_init` 程序化写入（卡带不携带
二进制资产），3×5 微型数字字模同样运行时烘焙；颜色全部直取 SPEC §2.2 固定色表。

## 难度与规则

| 难度 | 提示数 | 挖洞方式 |
|---|---|---|
| 入门 | 约 40 | 中心对称 + 唯一解验证 |
| 进阶 | 约 32 | 中心对称 + 唯一解验证 |
| 困难 | 约 26 | 中心对称 + 唯一解验证 |

- **题库生成**：以开局帧号为种子，随机候选顺序回溯生成完整终盘，再中心对称挖洞；
  每移除一格（对）都用「解数计数器（最多数到 2）」验证唯一解，不唯一立即回填。
  全程在协程中分帧执行（每帧限定切片数），出题画面显示阶段与进度条。
- **判定**：81 格全部与答案一致即胜利；允许存在错误填入（不强制即时判错），
  填错次数会计入结算；错误盘面可用 Ⓧ 检查或 Ⓡ 提示解围。
- **铅笔候选**：Ⓛ 开启后 Ⓐ 填入的是格内 3×3 小字候选，再次 Ⓐ 切换取消；
  任何数字落定都会自动清理同行/列/宫的同数候选。
- **提示**：每局 3 次，Ⓡ 揭示光标格正确答案（绿色数字）。
- **冲突检查**：Ⓧ 开关，标红所有与所在行/列/宫重复的数字。
- **计时与纪录**：mm:ss 计时（暂停停表）；各难度最佳用时存 `dset(0..2)`（整数秒）、
  最少提示用量存 `dset(3..5)`（存"用量+1"，0 = 未记录），音乐开关存 `dset(6)`，
  `fflush` 持久化。
- **数字条余量**：底部 1-9 按键实时显示每种数字剩余可填数量，填满 9 个自动变暗。

## 操作

| 键 | 功能 |
|---|---|
| ⬅⬆⬇➡ | 移动光标（按住自动重复；底行再按 ↓ 直达数字条）；标题画面选难度 |
| Ⓐ | 呼出数字条 / 确认填入（铅笔模式下填候选小字）；菜单确认 |
| Ⓑ | 擦除光标格（铅笔模式下只清候选）；数字条上返回棋盘 |
| ⬅➡（数字条）| 选数（按住自动重复）；⬆ 返回棋盘 |
| Ⓛ Ⓧ Ⓡ | 铅笔候选 / 冲突检查 / 提示——数字条聚焦时同样可用 |
| Start | 暂停菜单（继续 / 重开本题 / 换一题 / 返回难度选择） |
| Select | 音乐开关（任意画面） |

## 特性

- 分帧确定性出题：`srand(frame())` + PCG32，协程切片 + MRV 唯一解验证，
  出题期间可随时 Start 返回标题。
- 深浅棋盘格纸面 + 三层高亮：光标行列宫淡染、同数金色高亮、冲突红染；
  给定数字双描白字、玩家青蓝、提示绿、铅笔灰（3×5 微型字模 sspr 绘制）。
- 填数音效按数字映射 G 大调五声音阶（1-9 各自变调）；移动/擦除/填错/拒绝/
  提示/检查/胜利/新纪录各司其职；原创 C 五声 4 小节舒缓 BGM 回环（ch4-5）。
- 胜利演出：按 (行+列) 对角时序的金波扫场 + 结算面板（难度/用时/提示/填错/
  新纪录闪烁），Ⓐ 同难度再来一局。

## 构建与运行

```bash
cargo run -p fc16-tools --bin fc16mk -- --name "数独" --author "FrostMiKu" \
  --version 1 --code demo/sudoku/sudoku.lua --cover 120 \
  --out demo/sudoku/sudoku.fc16 --png demo/sudoku/sudoku.fc16.png
cargo run -p fc16-host -- demo/sudoku/sudoku.fc16
```

headless 验证（零输入 300 帧 + 输入脚本长跑；出题为分帧生成，脚本帧号需为
生成过程留足等待）：

```bash
cargo run -p fc16-host -- demo/sudoku/sudoku.fc16 --frames 300 \
  --screenshot out.png
cargo run -p fc16-host -- demo/sudoku/sudoku.fc16 --frames 900 \
  --script script.txt --screenshot out.png
```
