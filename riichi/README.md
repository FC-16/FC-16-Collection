# 日本麻将（立直麻将）· FC-16

FC-16 上的完整日本麻将（立直麻将）：四人东风战，25000 点起点，
136 张牌（五万 / 五筒 / 五条各一张红 5），支持 1–4 人热座（其余 AI 补位）
与全 AI 观战。全部规则逻辑、麻将牌精灵、SFX 与 BGM 均由单个
`riichi.lua` 程序化生成，卡带不携带二进制资产。

## 规则范围

- **对局**：东风战（东一～东四局），掷骰定起家，连庄（庄家和了或流局听牌则
  本场 +1 继续），庄家离任即终局；有人跌破 0 分立即终局（不允许负分借点），
  按点数排名（同分按起家顺位）。
- **牌与王牌**：136 张标准配置；王牌区 14 张，每次杠翻新宝牌指示牌并从岭上
  补牌（最多 4 杠 5 指示牌）。
- **和了形**：标准 4 面子 1 雀头、七对子、国士无双；荣和 / 自摸两路径，
  **无役不能和**。
- **鸣牌**：吃（仅上家，三种变体）、碰、大明杠、暗杠、加杠；鸣牌优先级
  荣和 > 碰 / 杠 > 吃，多家荣和均成立（立直棒归头跳家）。
- **立直**：门清听牌 + 1000 点宣告；宣告后自动摸切、自动和牌；两立直、一发、
  里宝牌、立直棒供托齐全；振听按河内牌与见逃规则处理。
- **流局**：荒牌流局（听牌宣告 + 不通符 3000 点分配）、四家立直流局。
- **计分**：标准符 / 翻体系（七对子固定 25 符、平和 20 符、切上满贯），点数按
  100 点向上取整；庄家 / 子家 × 荣和 / 自摸四列；本场费（荣和 300 / 自摸各家
  100）；满贯 8000 / 跳满 12000 / 倍满 16000 / 三倍满 24000 / 役满 32000
  （庄家 ×1.5），多役满累加。

### 简化项

- 抢杠（加杠被荣和）、大明杠抢杠无未和判定；加杠后宝牌指示牌即时翻开
  （标准为打牌后翻）。
- 九种九牌流局、四风连打、四杠散了（第 4 杠后继续对局）、三家和了头跳
  （全部成立）、流局满贯（ nagashi ）未实现。
- 加杠后的岭上自摸与暗杠保持听牌判定按向听数简化（AI 立直后不杠）。
- 荒牌流局的听牌宣告自动判定（不提供隐瞒选项），听牌手牌全部公开。
- 同分顺位按起家顺位，不加赛。

## AI 三档

- **简单**：纯向听数贪心切牌，进张面最宽优先；不鸣牌、不立直，能和就和。
- **普通**：向听数 + 牌效率（保留宝牌与红 5、先切孤立字牌 / 幺九）；听牌即
  立直（点数足够时）；断幺 / 役牌 / 对对路径的吃碰判断；荣和判断。
- **困难**：普通基础上增加防守（他家立直后按现物 → 筋 → 安全度排序切牌）、
  立直时机（好型听牌与点数局势）、鸣牌节制、终局顺位意识（四位终局激进进攻、
  领先保守）。

AI 决策为确定性规则（同分按固定顺序打破），不产生非法操作。

## 操作

| 键 | 功能 |
|---|---|
| ⬅ ➡ | 选牌 / 菜单选择（按住重复） |
| Ⓐ | 打出选中的牌 / 确认 / 和牌 |
| Ⓑ | 取消立直宣言 / 关闭杠菜单 / 鸣牌时过 |
| Ⓧ | 杠菜单（暗杠 / 加杠） |
| Ⓨ | 立直宣言（仅听牌后可打出的牌生效） |
| Start | 暂停（继续 / 役种表 / 退出对局） |
| Select | BGM 开关 |

多人热座时切换操作者会出现遮蔽画面（"轮到 P3"），非当前操作者的手牌以
牌背显示，鸣牌 / 立直 / 和牌提示仅对当前行动者可见。

标题画面可选玩家数（1–4 / 观战）、AI 难度（简单 / 普通 / 困难）与音乐开关；
战绩（局数 / 和了数 / 立直数 / 最佳点数，1P 视角）持久化到卡带存档。

## 自测

打包时向自由区首字节写入 `42`（`printf '*'` 一字节文件经 `--free` 注入）即进入
核心逻辑自测模式：71 项断言覆盖和牌判定、各役种（平和 / 断幺九 / 立直 + 宝牌 /
七对子 / 混一色 / 对对和 + 三暗刻 / 国士无双 / 四暗刻 / 三色同顺 / 一气通贯 /
混全带幺九 / 大三元 / 绿一色 / 字一色 / 九莲宝灯 / 四杠子 + 四暗刻双役满 /
混老头 / 小三元 / 两立直 + 一发 + 里宝牌 / 红宝牌 / 无役拒和）、符计算
（门前荣和 40 符 vs 自摸 30 符、役牌 40 符、七对 25 符）、点数表抽查
（子 3 翻 30 符 3900 / 子 4 翻 30 符 7700 / 亲 2 翻 40 符 3900 / 满贯 8000 /
役满亲荣和 48000 等）与向听 / 待牌枚举。结果经 `printh` 输出到终端并显示
汇总画面。

## 构建与运行

```bash
cargo run -p fc16-tools --bin fc16mk -- --name "日本麻将" --author "FrostMiKu" \
  --version 1 --save-id riichi --code demo/riichi/riichi.lua --cover 50 \
  --out demo/riichi/riichi.fc16 --png demo/riichi/riichi.fc16.png
cargo run -p fc16-host -- demo/riichi/riichi.fc16
```

自测卡带（会先运行自测再进标题）：

```bash
printf '*' > /tmp/t42.bin
cargo run -p fc16-tools --bin fc16mk -- --name "日本麻将" --author "FrostMiKu" \
  --version 1 --save-id riichi --code demo/riichi/riichi.lua --free /tmp/t42.bin \
  --out /tmp/riichi-test.fc16 --png /tmp/riichi-test.fc16.png
cargo run -p fc16-host -- /tmp/riichi-test.fc16 --frames 60
```
