# 黑白棋 · FC-16

FC-16 幻想主机上的完整黑白棋（Reversi/Othello）演示卡带：标准 8×8 棋盘、
三档难度 AI、全套程序化生成的美术与音乐（棋盘、棋子、SFX、BGM 均由 `_init`
逐字节写入，卡带不携带二进制资产；颜色全部直取 SPEC §2.2 固定色表）。

## 规则

- 标准 8×8 黑白棋：玩家执黑先行，AI 执白。落子必须至少夹翻一枚对方棋子，
  8 个方向全部翻转；无合法手时自动跳过（横幅提示"×无子可下"）；
  双方均无手或棋盘下满即终局，子多者胜。
- 棋盘为经典绿毛毡相间格 + 木框 + 四角星位标记，格边 24px。
- 战绩按难度累计 胜/负/和，`dset(0..8)` + `fflush` 持久化；音乐开关存槽位 9。

## 难度

| 难度 | AI 策略 |
|---|---|
| 入门 | 贪心：翻最多 + 本局种子的随机扰动（`srand` + `rnd`，全程确定） |
| 进阶 | 位置权重贪心：角最大、角旁（X/C 位）为负、边正，附送角惩罚与行动力压制 |
| 困难 | α-β 剪枝 minimax 深度 4，评估 = 位置权重 + 行动力 + 潜在翻转（前线子差）；终盘空格 ≤ 9 时改为精确求解至终局（以最终子差计分） |

## AI 的分帧执行

困难难度的搜索运行在 `coroutine` 中，按每帧固定的节点/候选段预算切片执行
（超预算即 `coroutine.yield`，下一帧续跑），思考期间显示"思考中…"脉动，
思考帧数不计入任何超时。搜索完全确定：手序按位置权重降序、同权按格序升序
（总序插入排序），评估状态（权重和 / 前线子数 / 空邻居计数 / 空格数）随
落子与回退增量维护，不走平台随机。

## 操作

| 键 | 功能 |
|---|---|
| ←→↑↓ | 移动光标（可按住连移；光标旁显示 C4 式坐标） |
| Ⓐ | 落子（标题画面与终局面板为开始 / 再来一局） |
| Ⓧ | 悔棋（成对撤回最近的玩家 + AI 两手，不限次数；思考与演出期间禁用） |
| Start | 暂停菜单：继续 / 认输 / 重开 / 回标题 |
| Select | 音乐开关（任意画面可用） |

## 特性

- **演出**：落子弹跳缩放入场；翻转按距落子点的切比雪夫距离错峰播放
  （横向椭圆压缩再展开模拟翻面，中途变色），翻转音效逐枚轻微升调；
  AI 落子处金环脉动提示；非法落子红闪 + 光标抖动 + 噪声拒绝音。
- **HUD**：右侧信息板（双方棋数 + 黑白比例条 + 当前手脉动指示灯 +
  难度 / 用时 / 手数），顶栏回合状态，底栏轮换提示行。
- **音频**：落子 / 翻转 / 非法 / 跳过 / 胜负和 SFX + 原创 D 小调安静棋类
  BGM（4 小节循环，ch4 旋律 ROUND + ch5 贝斯 BASS，MUSIC 行 0-3 回环），
  全部 SFX/MUSIC 由 `_init` 程序化烘焙（SPEC §4.2/§5.2）。
- **终局面板**：黑白子数对比条 + 胜负大字 + 各难度战绩（本难度行高亮，
  获胜闪"★"），Ⓐ 再来一局、Start 回标题。

## 构建与运行

```bash
cargo run -p fc16-tools --bin fc16mk -- --name "黑白棋" --author "FrostMiKu" \
  --version 1 --code reversi/reversi.lua --cover 30 \
  --out reversi/reversi.fc16 --png carts/reversi.fc16.png
cargo run -p fc16-host -- reversi/reversi.fc16
```

headless 验证（截图 + 输入脚本）：

```bash
cargo run -p fc16-host -- reversi/reversi.fc16 --frames 300 \
  --screenshot out.png
printf '60 key 4\n62 key -\n100 key 4\n102 key -\n' > script.txt
cargo run -p fc16-host -- reversi/reversi.fc16 --frames 900 \
  --screenshot out.png --script script.txt
```
