# 连连看 · FC-16

FC-16 幻想主机上的完整连连看演示卡带：三种难度、经典"最多 2 拐点"消除规则、
死局自动洗牌与提示系统，以及全套程序化生成的美术与音乐（28 种 16×16 图标、
全部 SFX、8 小节循环 BGM 均由 `_init` 逐字节写入，卡带不携带二进制资产；
颜色全部直取 SPEC §2.2 固定色表）。

## 难度与规则

| 难度 | 棋盘 | 对数 | 首关时限 |
|---|---|---|---|
| 入门 | 8×4 | 16 对 | 100 秒 |
| 标准 | 14×4 | 28 对 | 120 秒 |
| 挑战 | 14×8 | 56 对 | 150 秒 |

- **消除规则**：两张相同图标，能够用**最多 2 个拐点**（3 段正交线段）的路径
  连通即可消除；路径只能经过空格与棋盘外圈的一圈虚拟空格。判连按拐点数
  0/1/2 分层枚举，枚举顺序固定 → 路径与提示完全确定性。
- **计时**：时间条倒数，每次消除 +2 秒（不超过上限）；每过一关时限 -10 秒
  （下限 40 秒）。时间归零即游戏结束。低于 20% 时间条红色闪烁，剩 20 秒
  有一次提醒音。
- **连击**：4 秒窗口内连续消除，分数递增（10 / 15 / 20 …，8 级封顶），
  消除音效音高同步上升 8 级；窗口内消除飘字转金色。
- **过关**：清空棋盘即过关，按剩余时间结算时间奖励（每秒 5 分），
  随后自动重新发牌进入下一关，无限循环冲击最高分。
- **死局**：后台增量扫描保证每帧最多测试 24 个候选对；一旦无可连对，
  自动洗牌（剩余图标原地重排，带缩放动画与音效）。洗牌后仍无对则再次洗牌。
- **发牌**：每局以 `srand` 本局种子做确定性 Fisher-Yates 洗牌，逐格错峰
  生长入场；图标 28 种（14 种形状 × 2 配色），每种出现偶数次。

## 操作

| 键 | 功能 |
|---|---|
| ⬅⬆⬇➡ | 移动光标（长按连发；标题画面选难度） |
| Ⓐ | 选中 / 消除（标题开始；结算后重来） |
| Ⓑ | 取消选中（暂停中继续） |
| Ⓡ | 提示一对可连牌（高亮 3 秒，每关 3 次） |
| Select | 局内手动洗牌（每关 2 次）；标题 / 暂停 / 结算画面为音乐开关 |
| Start | 暂停 / 继续（结算画面回标题） |

## 特性

- 圆角浮雕牌面（亮棱 / 暗棱 / 高光）、空格凹陷底色、光标四角括号随呼吸脉动、
  选中金色光圈；消除时两牌缩小碎裂 + 粒子飞溅 + 沿实际路径高亮连线 18 帧
  （金色晕 + 闪烁核心，端点亮点）。
- 提示对以青色闪烁括号标出；不可连的同图对双双抖动 + 拒绝音。
- 洗牌为全体缩出 → 重排 → 错峰长入的三段动画；过关有随机金色爆发 + 扩散环。
- HUD：关卡 / 分数 / 最高分 / 时间条 / Ⓡ 与洗牌余量 / 音乐标记；
  底栏轮播操作提示。
- 最高分 `dset(0)`、音乐开关 `dset(1)`，`fflush` 持久化。
- 音频：原创 C 大调五声 8 小节循环 BGM（旋律 ROUND / 琶音 TRIANGLE /
  贝斯 BASS / 鼓组噪声，PATTERN 0-7 BEGIN/END 回环，占 ch4-7）；
  选中 / 消除（连击 8 级音高）/ 拒绝 / 洗牌 / 提示 / 过关 / 时间到 / 新纪录 SFX 走 ch0-2。

## 构建与运行

```bash
cargo run -p fc16-tools --bin fc16mk -- --name "连连看" --author "FrostMiKu" \
  --version 1 --code demo/lianliankan/lianliankan.lua --cover 120 \
  --out demo/lianliankan/lianliankan.fc16 --png demo/lianliankan/lianliankan.fc16.png
cargo run -p fc16-host -- demo/lianliankan/lianliankan.fc16
```

headless 验证（零输入截图 + 输入脚本开局消除一对，注意 seed 0 会被宿主映射为
随机种子，固定请用 `--seed 1`）：

```bash
cargo run -p fc16-host -- demo/lianliankan/lianliankan.fc16 --frames 150 \
  --screenshot out.png
cargo run -p fc16-host -- demo/lianliankan/lianliankan.fc16 --frames 900 --seed 1 \
  --script script.txt --screenshot out.png
```
