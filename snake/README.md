# 贪吃蛇 · FC-16

FC-16 幻想主机上的完整贪吃蛇演示卡带：三种模式、三档速度、平滑插值移动与全套
程序化生成的美术与音乐（精灵、SFX、BGM 均由 `_init` 逐字节写入，卡带不携带
二进制资产；颜色全部直取 SPEC §2.2 固定色表）。

## 模式与规则

| 模式 | 规则 |
|---|---|
| 经典 | 四边致命，撞墙 / 撞自己 / 撞障碍即死 |
| 穿墙 | 四边环绕互通（边界以流动青色虚线提示），撞自己即死 |
| 障碍 | 经典规则 + 固定障碍阵（四条横栏 + 中央方墩，出生行畅通） |

- 网格 16×14，逻辑格移动 + **渲染插值**：蛇身按步进间进度平滑滑动而非跳格，
  体节间桥接补缝，穿墙处两侧补画保持连续。
- 转向禁止 180° 回头（两级输入缓冲，先按先转）：方向入队即刻**预转向 + 轻响**，
  网格转向仍在下一步进生效；入队时按生效方向校验轴向，同轴含 180° 当场拒收、
  不占缓冲位。吃食后按 `间隔 = max(基础-4, 基础-进食数×0.25)` 渐进加速，封顶 -4 帧/格。
- 食物：普通苹果 +1 节 +10 分；每吃 5 个苹果出现限时 6 秒的**金色星果**
  （+50 分，光环脉动、呼吸缩放，临近消失时闪烁，吃到有金色爆发 + 扩散环演出）。
- 连吃窗口 6 秒：窗口内每次进食的音效音高逐级上升（8 级）。
- 死亡演出：绘制期 + 显示期双重调色映射闪红、头部撞击回弹、震屏，
  身体自尾向头逐节碎裂成粒子，最后头部爆裂并弹出结算面板。
- 分模式最高分 `dset` + `fflush` 持久化（槽位 0/1/2），音乐开关存槽位 3。

## 操作

| 键 | 功能 |
|---|---|
| ⬅⬆⬇➡ | 转向（标题画面为选模式 / 速度） |
| Ⓐ | 标题开始 / Game Over 后再来一局 |
| Ⓑ 或 Start | 暂停 / 继续 |
| Select | 音乐开关（标题 / 游戏 / 暂停中均可） |

## 音频

8 声部芯片配器：旋律 ROUND、琶音 TRIANGLE、贝斯 BASS、鼓组（长/短噪声），
MUSIC 行 0-7 以 LOOP_START/LOOP_BACK 回环，占 ch4-7；游戏音效走 ch0-2。BGM 为原创
A 小调五声 8 小节循环。吃食音高随连吃次数上升，死亡为下滑锯齿，
新纪录有独立号角旋律。

## 构建与运行

```bash
cargo run -p fc16-tools --bin fc16mk -- --name "贪吃蛇" --author "FrostMiKu" \
  --version 1 --save-id snake --code snake/snake.lua --cover 30 \
  --out snake/snake.fc16 --png carts/snake.fc16.png
cargo run -p fc16-host -- snake/snake.fc16
```

headless 验证（零输入 400 帧 + 输入脚本长跑，注意 seed 0 会被宿主映射为
随机种子，固定请用 `--seed 1`）：

```bash
cargo run -p fc16-host -- snake/snake.fc16 --frames 400 --screenshot out.png
cargo run -p fc16-host -- snake/snake.fc16 --frames 6100 --seed 4 \
  --script script.txt --screenshot out.png
```
