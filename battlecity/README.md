# 坦克大战 ・ FC-16

致敬 Namco 1985 年《Battle City》的单人战役坦克大战。玩法、敌人构成与
关卡布局忠实还原经典（STAGE 1-10 的地形与每关 20 辆敌坦出场序均转写自
原作 ROM 的出厂关卡表，属公开的事实数据）；像素美术与全部音频为本卡带
原创，以 FC-16 出厂 64 色手绘烘焙。

## 规则

- 战场 13×13 大格（208×208px）居中，右侧 48px 信息栏显示敌方余量、关卡、命数与得分
- 玩家 3 命起，出生自带 2 秒护盾；中弹损毁扣命并于出生点重生，火力清零
- 每关 20 辆敌坦，场上同时最多 4 辆，左 / 中 / 右三个出生点轮转，出生闪星后现身
- 第 4、11、18 辆为红色闪烁的道具坦克：首发命中掉落道具（不掉本体）
- 全灭 20 辆过关 → 计分结算 → 幕布转场下一关；打满 10 关进入胜利画面
- 基地鹰被任意一方炮弹击毁，或命数耗尽，即 GAME OVER；可续关（本关重来、分数清零）

### 地形

| 地形 | 行为 |
|---|---|
| 砖墙 | 8×8 半格为破坏粒度，一发清 16×8 缺口 |
| 钢墙 | 挡车挡弹，3 级火力弹可摧毁 |
| 水 | 挡车不挡弹 |
| 树 | 不阻挡，树冠盖在坦克上层 |
| 冰 | 松开方向后按惯性滑行 |

### 敌人（击破分值）

| 型号 | 特性 | 分值 |
|---|---|---|
| 基本 | 银灰，慢速 | 100 |
| 快速 | 青色，速度与玩家相当 | 200 |
| 火力 | 红色，快弹、射速高 | 300 |
| 装甲 | 绿色，4 血，每中一弹变色（绿→金→蓝钢→银） | 400 |

敌坦 AI 巡行随机转向、偏好向下与朝基地方向推进，与玩家或基地同线即开火。
道具拾取额外 +500 分。

### 道具（道具坦克掉落，闪烁悬浮于场）

| 道具 | 效果 |
|---|---|
| 头盔 | 护盾 10 秒 |
| 定时 | 冻结全部敌坦 8 秒（变灰） |
| 铁锹 | 基地围墙变钢 15 秒，末段砖 / 钢交替闪变后复原 |
| 星星 | 火力 +1 级（1 级弹速加快，2 级屏上双发，3 级可摧钢） |
| 手雷 | 全灭场上敌坦（不计分） |
| 坦克 | 命数 +1 |

## 包含关卡

STAGE 1 - STAGE 10，布局逐半格还原原作出厂表（六砖柱、钢块要塞、水道、
林海、冰原等经典布阵悉数在列）；通关后进入胜利结算。最高分与最远关卡经
`dset` / `fflush` 存档（存档槽 save_id = `battlecity`）。

## 操作

| 键 | 功能 |
|---|---|
| ⬅⬆⬇➡ | 移动（转向时垂直轴自动吸附 8px 半格） |
| Ⓐ | 开火 |
| Start | 暂停 / 继续（暂停画面附操作说明） |
| Select | 背景音乐开关 |

音频：引擎待机 / 行进双态噪声长音、开火、击砖、击钢弹开、命中、爆炸、
拾取、关卡号角、结算滴答与失败 / 过关 / 胜利旋律；BGM 为原创 A 小调进行曲
（方波旋律 + 贝斯 + 噪声鼓三轨 8 小节循环），全部由 `_init` 程序化写入，
卡带不携带二进制资产。

## 构建与运行

```bash
cargo run -p fc16-tools --bin fc16mk -- --name "坦克大战" --author "FrostMiKu" \
  --version 1 --save-id battlecity --code demo/battlecity/battlecity.lua \
  --out demo/battlecity/battlecity.fc16 --png demo/battlecity/battlecity.fc16.png --cover 120
cargo run -p fc16-host -- demo/battlecity/battlecity.fc16
```

精灵表（玩家 4 向 × 2 履带帧、四型敌坦、砖 / 钢 / 水 / 树 / 冰、鹰基地、
六种道具、爆炸三帧、出生闪星、子弹、面板图标）全部由 `_init` 逐像素
`poke` 烘焙；敌坦变色（装甲掉血 / 冻结 / 道具坦克闪烁）经绘制期 `pal`
重映射实现，不重复烘焙瓦片。
