# 五子棋 · FC-16

经典连珠五子棋。15×15 标准棋盘，黑先白后，任意方向（横、竖、两条斜线）
先连成五子或以上者胜（长连也算赢，简化规则），下满 225 手为和棋。
木纹棋盘、棋子高光、连线动画与全部音效均由 `_init` 程序化生成，
卡带不携带二进制资产。

## 模式

- **双人对弈**：同屏轮流执子。
- **人机对战**：玩家执黑先行，AI 执白；AI 落子前有约半秒的"思考"演出。

## AI 策略

启发式棋型评分，单帧内完成：

- 候选点：已有棋子切比雪夫距离 2 以内的全部空点，AI 只会落在空点；
- 对每个候选点按 4 个方向统计"虚拟落子后"的连子长度与两端开放数，
  棋型分序为 连五 > 活四 > 冲四 > 活三 > 眠三 > 活二 > 眠二，四方向求和；
- 最终分 = max(己方进攻分, 对方同点分 × 0.85 防守权重)：己方能连五立即
  取胜；对方连五/活四点优先封堵；同分先取更靠近天元的点，再按扫描序，
  全程确定、无随机数。

悔棋：双人对弈退一手；人机对战退两手（回到玩家上次落子前）；AI 思考中
按 Ⓑ 会取消思考并退回玩家那一手。胜负已分后不再悔棋。

## 操作

| 键 | 功能 |
|---|---|
| ⬅ ➡ ⬆ ⬇ | 移动光标（按住自动重复：首帧一格，停 14 帧后每 4 帧一格） |
| Ⓐ | 落子（已占点会蜂鸣拒绝） |
| Ⓑ | 悔棋 |
| Start | 标题画面开始 / 对局中回标题 / 终局回标题 |
| Select | 环境音乐开关（持久化） |

胜负演出：五连子闪烁高亮 + 红色连线动画 + 胜负横幅（横幅自动落在
五连行下方，不遮挡棋型）。

## 音频

- 黑白落子为不同音色（圆润低叩 / 铃音高叩）、悔棋下行双音、
  胜利上行旋律、和棋中性双音、非法落子噪声；
- 可选环境 BGM（Select 开关，默认开启）：C 大调五声音阶小品，
  旋律（ROUND）+ 贝斯（BASS）两条声部，四小节 Pattern 回环 12.8 秒，
  经 music mask 独占 ch4/5，与音效通道互不抢占。

## 存档

战绩统计（双人：黑胜/白胜/和；人机：胜/负/和）与音乐开关经
`dset`/`fflush` 持久化（save-id `gomoku`）。

## 构建与运行

```bash
cargo run -p fc16-tools --bin fc16mk -- --name "五子棋" --author "FrostMiKu" \
  --version 1 --save-id gomoku --code demo/gomoku/gomoku.lua --cover 90 \
  --out demo/gomoku/gomoku.fc16 --png demo/gomoku/gomoku.fc16.png
cargo run -p fc16-host -- demo/gomoku/gomoku.fc16
```

封面取标题画面第 90 帧（`--cover 90`）。
